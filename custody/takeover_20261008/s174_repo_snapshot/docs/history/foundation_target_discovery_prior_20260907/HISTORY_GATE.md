# Mandatory historical gate for every Target Discovery iteration

Status: `BINDING_PROCESS_RULE__NO_SCIENTIFIC_AUTHORITY`

Before computing, promoting, or renaming a target hypothesis, answer:

1. Was the same mathematical object already tried?
2. Was a close surrogate tried under another name?
3. Was it only a representation winner, or did it actually earn biological target authority?
4. What exact failure or limitation prevented historical promotion?
5. What material condition is different now?

If #5 has no concrete answer, do not rerun the candidate under a new name.

- `FALSIFICATION_ONLY`
