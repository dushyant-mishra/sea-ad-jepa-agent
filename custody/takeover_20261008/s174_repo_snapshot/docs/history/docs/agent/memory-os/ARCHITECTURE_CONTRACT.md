# ARCHITECTURE CONTRACT
- Objective: infer latent biological programs/states from incomplete RNA evidence.
- H remains gene/address-resolved; global state cannot replace molecular accountability.
- Measured zero is evidence; structurally unmeasured and collision-unresolved are distinct states.
- Teacher receives richest physically available evidence, not invented measurements.
- Teacher must be trained and biologically qualified; pathology is forbidden.
- Student receives partial evidence and predicts qualified teacher representations/states.
- Exact hidden-transcript imputation is not the primary objective.
- Cascade preserves broad visible context/address opportunity and progressively emphasizes targets/queries:
  broad -> weak/local -> core+halo -> sparse/rare/innovation.
- Preserve complementary halo evidence; do not implement cascade as tier evidence starvation.
