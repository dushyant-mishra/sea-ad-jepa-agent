# Cleanup Manifest

This manifest records local result cleanup so the repository stays readable while preserving audit trails.

## Policy

Archive, do not delete, exploratory artifacts unless they are clearly disposable and regenerated by a documented command.

Keep active or narrative artifacts in place:

- active Stage A full training outputs
- main v2.1/v2.2 reports
- README/dashboard figures
- adapter alignment summaries
- current best checkpoints
- raw and processed H5AD files

Archive local-only smoke and benchmark artifacts:

- files with `smoke` in the name
- files with `benchmark` in the name
- smoke-test model folders
- benchmark model folders
- smoke/benchmark TensorBoard run folders
