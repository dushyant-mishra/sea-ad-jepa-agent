# v3 Frozen Artifact Index

This index protects the v3/Stage75-79 work while v4 development begins. It records the scientific role of the frozen artifacts without moving paths that may be referenced by manifests, docs, configs, or hashes.

## Core v3 Scientific Center

The durable v3 result is the self-supervised Graph-JEPA representation: disease-relevant microglial state structure emerged without training the model as a disease-label classifier.

## Regulatory/Perturbation Boundary

Stage75-79 regulatory and perturbation outputs are retained as bounded computational provenance. The frozen v3 perturbation simulations produced technically valid but extremely small latent shifts relative to the natural JEPA geometry. They should be treated as calibration and feasibility evidence, not as biologically meaningful state-control evidence.
