# TOKEN_EFFICIENT_PROTOCOL_V2.md

## Goal
Preserve scientific rigor while minimizing repeated Codex context/output cost.

## Operating pattern
1. One fresh Codex thread per major scientific gate.
2. Stable root `AGENTS.md` = mission, topology, invariants, context map.
3. `ACTIVE_STATE.md` = only current decision-changing state.
4. `EVIDENCE_INDEX.md` = selective retrieval map to deep history.
5. One active execution plan = current scientific boundary.
6. Routine engineering stays with coordinator.
7. Up to three scoped critics only after relevant metrics exist.
8. Full board only for objective/representation/firewall/training authorization/freeze.
9. Critics receive scoped evidence, not the entire v4 history.
10. Large logs/tables/provenance are files, not chat dumps.
11. Prefer `rg`, targeted reads, line slices, compact JSON/CSV summaries.
12. Keep stable context files unchanged when possible.
13. Update ACTIVE_STATE only with new decision-changing evidence.
14. Do not spend tokens reproducing historical fixtures unless the result can change the next decision.
15. Historical 4,096 mechanism artifacts never displace the real production (~41K) path.

## Critic response format
- VERDICT
- three strongest findings
- one most important blocker/falsification
- exact artifact references
- <=600 words by default
