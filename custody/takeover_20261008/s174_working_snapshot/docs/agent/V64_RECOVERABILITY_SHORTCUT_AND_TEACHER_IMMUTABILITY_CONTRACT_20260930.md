# V64 recoverability shortcut and teacher-immutability contract

**Date:** 2026-09-30  
**Status:** PROSPECTIVE QUALIFICATION CONTRACT — no biological threshold frozen

## 1. High RNA predictability is necessary but not sufficient

A privileged factor can be highly predictable from RNA because both the RNA input and the privileged measurement respond to the same technical or generic activity driver.

Examples include:
- library/capture depth;
- detected-gene count;
- global transcriptional activity;
- promoter accessibility coupled to expression;
- evidence availability;
- dataset/operator identity.

Therefore:

`high held-out RNA recoverability != qualified biological shared state`

without comparator and shortcut gates.

## 2. Required baseline hierarchy

For each privileged factor/subspace, compare the lawful RNA predictor against predeclared simple baselines representing plausible shortcuts.

As applicable:
- technical descriptors only;
- library depth / detected-gene count only;
- generic global RNA state;
- simple expression/activity proxy;
- evidence-availability indicator;
- dataset/operator identity where lawful as a diagnostic.

A factor that is predicted as well by a simple shortcut baseline as by the candidate RNA representation does not establish a biologically useful shared target.

## 3. Teacher/factor immutability during recoverability qualification

The privileged factor being tested must be locked before TEST recoverability is evaluated.

Forbidden:
- jointly moving the privileged factor to become easier for the RNA student;
- rotating the factor on TEST to maximize predictability;
- selecting privileged dimensions after seeing TEST recoverability;
- changing privileged-factor normalization based on student performance.

If the privileged encoder itself is learned, its parameters and factor definition must be frozen using development data before final recoverability testing.

## 4. RNA contribution to privileged factor construction

If RNA enters privileged-factor construction, recoverability may become tautological.

Every factor must declare:
- whether RNA entered construction;
- which RNA features entered;
- whether the exact student-visible RNA entered;
- whether the factor has a privileged-only component.

A factor whose apparent recoverability is guaranteed by direct reuse of student-visible RNA cannot qualify merely from prediction accuracy.

Preferred development design for regulatory-private/shared qualification:
- construct a privileged regulatory factor from non-RNA regulatory measurements where feasible; or
- explicitly separate the RNA-derived and privileged-derived contributions before testing recoverability.

## 5. Baseline-relative interpretation

A future numerical decision contract must prospectively define a material advantage criterion.

This contract freezes only the logic:

- **high RNA prediction + high technical-baseline prediction** → shortcut concern, not biological qualification;
- **high RNA prediction + low simple-shortcut prediction** → candidate shared biology, still requires donor/dataset transport and biological validation;
- **low RNA prediction + strong privileged biological support** → candidate privileged-private state;
- **low measurement reliability** → unqualified, not private by default.

## 6. Availability

Evidence availability itself must be treated as a possible predictor.

The anchored-but-RNA-unmeasurable stratum is a deliberate negative probe where relevant.

Do not allow:
- missingness token;
- assay-presence flag;
- resource membership;

to become an undeclared route to recoverability.

## 7. Synthetic smoke semantics

Software smoke tests should include:
1. a true RNA-shared factor;
2. an independent privileged-private factor;
3. a shortcut factor predictable from RNA only through a technical driver.

Expected behavior:
- shared passes basic recoverability smoke;
- private fails RNA prediction;
- shortcut is highly predictable but is not distinguishable from the technical baseline and therefore must not be called biological shared state.
