# v4 Script Area

Scripts are reproducibility builders, not scientific conclusions. For the
current status and authoritative outputs, start at
[`../../START_HERE.md`](../../START_HERE.md). The script classification is
maintained in `configs/v4/v4_artifact_map.yaml`.

Use this directory for v4-specific helper scripts and runners. Shared utilities can stay in the top-level `scripts/` directory after review.

Initial expected scripts:

- feature-universe audit
- v3/v4 non-regression metric assembly
- v4 training manifest validation
- checkpoint/provenance verification

Keep exploratory scripts out of Git until their inputs, outputs, and claim boundaries are clear.
