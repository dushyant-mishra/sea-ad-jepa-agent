## 1. Scientific question and claim boundary

The primary T0 question is:

> Can a fixed, expression-only broad-IMMUNE molecular score learned on SEA-AD MTG discovery donors show a donor-disjoint positive association with quantitative MTG AT8 pathology, after predeclared nuisance, broad-IMMUNE composition, and measurement/technical sensitivities?

The secondary hierarchical question is:

> Conditional on the parent broad-IMMUNE expression target being supported, does the same frozen molecular direction contain a donor-recurrent extreme-cell tail whose prevalence carries AT8 information beyond the donor-wide state score?

V18 therefore has two nested estimands:

- `T0-I`: broad-IMMUNE donor-level continuous expression target;
- `T0-I-TAIL`: same-direction, mean-independent rare-tail prevalence extension.

V18 does **not** claim:

- a pure microglial target (`IMMUNE` is broader than pure microglia);
- a pure within-subtype molecular-state effect;
- a discrete cluster, neighborhood, or spatially localized subpopulation;
- exhaustive discovery of all rare disease biology;
- cross-source disease replication;
- causality, mechanism, biomarker validation, or therapeutic relevance;
- JEPA representation success.

A supported T0-I-TAIL is a recurrent extreme-cell **state tail**, not automatically a discrete subpopulation/neighborhood. A discrete/local claim requires a separate prospectively frozen geometry/spatial contract.

Historical Stage64 inspected related pathology-linked microglial/immune expression. V18 is therefore an internal target-qualification/revalidation study, not pristine first discovery or external confirmation.

## 9. Discovery target learner

Discovery uses only frozen `DISCOVERY` donors and the 28,061 scoring addresses.

For each donor:

1. normalize every cell using the canonical expression rule;
2. compute equal-cell donor pseudobulk over all frozen primary cells for that donor;
3. use canonical donor ordering by UTF-8 donor ID.

The target learner is a nuisance-partialled dual ridge.

For each leave-one-discovery-donor-out fold:

1. recompute the training-only age center;
2. fit the training nuisance model for pathology and each scoring feature;
3. residualize and scale using training-only quantities;
4. compute the dual ridge trace scale;
5. test the dimensionless multiplier exponent grid:

`[-6.0, -5.5, ..., 1.5, 2.0]`;

6. evaluate heldout donor squared error;
7. average errors over discovery donors.

Select the **largest multiplier exponent** whose CV loss is within the fixed numerical tie tolerance of the minimum. The absolute final lambda is recomputed from the full discovery set trace scale; it is not a hard-coded number.

The frozen target stores at least:

- beta;
- mu;
- sigma;
- decision-gene mask;
- complete multiplier grid and CV losses;
- selected multiplier index/exponent;
- final lambda and trace scale;
- response residual SD;
- discovery age center;
- canonical discovery donor order.

The deployed cell score is expression-only. It is algebraically the frozen standardized linear score; donor age/sex do not enter cell scoring.

## 11. Rare-tail threshold authority

The rare-tail extension uses the **same frozen continuous molecular direction**. No second disease direction is learned.

For each discovery donor, center cell scores by that donor's mean score.

A discovery donor contributes to the threshold only if it has >=80 primary cells. At least 10 discovery donors must be threshold-measurable.

The frozen tail threshold is the equal-donor empirical inverse CDF at q=0.95:

- each contributing donor has equal total weight;
- each cell within donor has weight `1/(D * n_d)`;
- sort centered scores;
- choose the smallest score whose cumulative weight is >=0.95;
- no interpolation.

Confirmation tail membership uses the strict comparison:

`centered_cell_score > frozen_threshold`.

## 12. Continuous-state confirmation inference

Parent-state inference always uses all 18 frozen confirmation donors.

Primary model:

`AT8 ~ nuisance + STATE_SCORE`.

Inference engine:

- HC3-studentized Freedman-Lane;
- exactly 9,999 deterministic donor residual permutations;
- fixed canonical 18-donor order and permutation authority.

Primary directional thresholds:

- positive support candidate: beta > 0 and upper one-sided p <= 0.025;
- contradiction candidate: beta < 0 and lower one-sided p <= 0.005.

A primary candidate is not enough by itself. To support the broad-IMMUNE expression target, the same direction must remain decision-capable and positive at one-sided p <=0.05 in:

1. the broad `IMMUNE_FRACTION` composition sensitivity;
2. the mandatory `Q_DEPTH + Q_DETECT` sensitivity;
3. every predeclared cumulative technical-sensitivity block.

A negative disqualification likewise requires the negative direction to survive the same mandatory sensitivity structure. Otherwise the result is underdetermined rather than disqualified.

Rank/df/leverage non-estimability returns an underdetermined terminal. Malformed, nonfinite, or semantically impossible inputs hard-fail.

## 14. Tail disease inference — V18 correction

The earlier n=17 studentized Freedman-Lane tail proposal is **rejected**. In fresh pathology-blind calibration, the worst combined false-terminal rate reached 6.25% for studentized Freedman-Lane and 5.83% for a wild-HC3 bootstrap comparator under heteroskedastic-tail nulls.

V18 tail disease inference instead uses:

`HC3 coefficient / HC3 standard error`, calibrated against a Student-t reference with the model's actual residual degrees of freedom.

Engine identifier:

`HC3_T_RESIDUAL_DF`.

Allowed tail-measurable donor counts:

- n=17;
- n=18.

Primary tail model:

`AT8 ~ nuisance + STATE_SCORE + TAIL_PREVALENCE`.

Primary directional thresholds:

- positive: beta_tail >0 and upper one-sided p <=0.020;
- contradiction: beta_tail <0 and lower one-sided p <=0.005.

The tail is explicitly testing **incremental distribution-shape information beyond the donor-wide state score**. A high-cell phenomenon that is merely a donor-wide score shift is not a positive T0-I-TAIL result.

If a primary direction qualifies, the same direction must remain decision-capable at one-sided p <=0.05 in:

1. `IMMUNE_FRACTION` composition sensitivity;
2. `Q_DEPTH + Q_DETECT` sensitivity;
3. every predeclared cumulative technical block.

All tail primary and tail sensitivity disease regressions use the HC3-t engine. Non-estimability gives underdetermined, not PASS/FAIL.
