## Governing rule

Historical evidence must be classified before reuse. Every prior result belongs to one of these classes:

- **mechanistic/architectural ancestor** — useful design precedent, not drop-in production authority;
- **narrow qualified component** — may be reused only inside its stated scope;
- **unfrozen diagnostic** — descriptive evidence only;
- **negative prior / falsified mechanism** — preserve and do not revive without a new prospective reason;
- **custody/interface pattern** — reusable software or blinding pattern, not biology;
- **human biological authority** — only if separately and explicitly qualified; synthetic evidence never creates this by itself.

The current synthetic production design must compose narrow valid components without flattening these classes.
