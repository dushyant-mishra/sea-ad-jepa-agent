## 2. Scientific objective; what teacher means

The project seeks **query-conditioned prediction of a biologically meaningful latent state**, not prediction of a hidden gene's scalar value and not reconstruction of a separately defined RNA panel masquerading as a teacher. A rich teacher must construct its measured state from biological observations assigned to it. A student receives only permitted complementary evidence and predicts that state. Test whether query identity changes the prediction and whether the state carries information beyond technical effects, generic cell identity and the queried gene itself.

The current V29 study tests the **measured per-nucleus program target construction** before fitting a neural teacher. Programs: APOE/lipid handling, P2RY12/homeostatic and HLA-DRA/antigen presentation, each comprising queried gene plus four measured partners. Six other RNA markers were reserved for a separate evaluation lane. The teacher-fidelity cross-program readout is a **same-nucleus, same-assay coherence test**, not orthogonal validation or a biological-causality proof.

Use existing extensive ETL, not new acquisition searches: committed GSE178317 perturbation/cell-guide assets, CRISPRbrain microglia and other screens, and existing external RNA/ATAC qualification. ## 5. Teacher-only fidelity statistical chronology and latest snapshot

Early teacher-fidelity protocols v1-v4 were prospectively amended after defects were detected before real outcomes. Ratio readouts induced spurious correlation through a shared denominator. A raw-count NB model with log D offset and split CLR/amplitude predictors removed the direct ratio but was **still confounded** in sparse RNA.

The first sparse NEG-2 synthetic arm (independent programs with common latent capture) falsely qualified: median increment +0.023, 73% donors positive, p=.02. Replication showed **39/40** independently generated NEG-2 datasets falsely qualified. The first abundance-matched sham derived capture from observed D, not the latent factor. Even reliability matching from D could not reproduce residual nuisance: real partial corr(amplitude, log capture | log D) +.4437 versus synthetic shams +.0031/+ .0092. A sham generated via **the same latent capture mechanism** gave partial residual correlations approximately .441/.452 and residual-readout correlations .197/.194 in a single seeded diagnostic; those two matches do NOT by themselves prove full exchangeability. Frozen protocol v7 **b2ce421622ebe56d34155b11739f26840798abb7** prospectively requires same-mechanism real-gene quadruple shams from the same nuclei on real data; v1-v6 remain historical records. The stopping rule permits no repeated threshold tuning if this final count-based route fails. Synthetic failure would invalidate this validation strategy under tested nuisance, NOT demonstrate absence of a per-nucleus biological state.

Our earlier audit PR #185 found gate-v3 flaws: POS_COMP loads (+.6,-.6,+.6,-.6) sum to zero but exponentiated total rises as 4 cosh(.6z), so near-zero linear amp-z correlation was deceptive; 9-sham smoke cannot pass p<=.05 (minimum p=.10); Python hash() seeds are process-dependent; NaN/undersampled calibration was fail-open; only one distinct NEG mechanism; sham nuisance gamma reused; positives not independently replicated; earlier NB fit silently fell back to Poisson or could fail non-converged.
