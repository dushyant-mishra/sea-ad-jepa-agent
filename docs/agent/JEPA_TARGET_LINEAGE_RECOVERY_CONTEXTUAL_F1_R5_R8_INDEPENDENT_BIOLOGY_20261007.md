## Recovered chronology

1. Historical direct rich-H / query-local latent matching produced mechanically real but biologically weak results. In the large V6R5B analysis, correct memory improved H-space reconstruction modestly, but the gain was mostly cell-global, attention routing was nearly diffuse/query-invariant, and biological program recovery was not demonstrated. The strict donor-cross-fit residual-target rescue was subsequently executed and did not rescue the protected biology.
2. The FULL104 shared-state derivation later terminated at `TEACHER_BIOLOGY_LIMIT` with `D_shared = null`. This closed that tested shared-state target family; it did not establish that FULL104 lacks biology.
3. `CONTEXTUAL_TEACHER_TARGET_V1` then passed F0 implementation/leakage mechanics, but its real F1 biological sweep never produced a decision-grade biological PASS/FAIL. The machinery became executable and repeatedly repaired through Sept 7, but the history still records real F1 as unauthorized / not run. u0 smoke effects were treated as mechanics only, not biological evidence.
4. The project then moved to explicit measured targets. R5 established a genuine query-conditioned prediction problem using non-q measured RNA context. A rich q-visible teacher was retained as a developmental incumbent, with a q-excluded ablation required. q scalar alone was a poor replacement for multigene context, while adding q to measured context gave only a small incremental R2 improvement.
5. R7 and R8 separated student predictability from teacher fidelity. R8 showed the APOE developmental anchor was predictably reconstructible from complementary RNA relative to a technical baseline, whereas P2RY12/HLA-DRA were not. R7's prespecified separate RNA readouts were negative for all three queried programs. Therefore `student_predictability != teacher_fidelity` is empirically demonstrated in the project history.
6. R16 demonstrated normalization/information-flow shortcuts in the historical numerical pipeline: q and forbidden partner/reference genes can leak through denominators and q-specific normalization coordinates. A common excluded coordinate basis removed the tested swap artifact on the bounded historical cells, but this is not a production-reader qualification.
7. No candidate target component has passed independent chromatin/protein fidelity. Morabito donor-level ATAC scoring was not executed. Aggregate/gene-level ATAC accessibility was later exposed, so any Morabito use requires an outcome-independence audit and donor-level pseudobulk endpoint frozen independently of those exposed values.
8. Historical Stage75F / SCENIC+ regulator hypotheses are not an independent biological answer key because the 10-regulator / 96-row hypothesis was derived from Morabito RNA. The regulatory evidence remains useful as a biological prior/hypothesis source, not as independent validation of an RNA-derived teacher.

## Strong surviving scientific distinctions

- Target meaning, target recoverability, and target uncertainty are separate gates.
- A target may be biologically meaningful yet only partially recoverable from lawful student evidence.
- A target may be predictable from complementary RNA yet fail independent biological fidelity.
- Richer teacher evidence may lawfully include q when it contributes to constructing state; anti-cheat rules belong primarily on the student and on target-fidelity tests, not as an automatic reason to strip the teacher of biologically relevant evidence.
- Whole-vector deterministic matching is unsafe when components have different recoverability ceilings. Component-level recoverability classes must be machine-enforced before Stage A.
- Independent modality evidence must be truly independent of target construction or explicitly classified as exposed/developmental.

## Implication for the next target design

Do not restart direct rich-H matching, strict residual-target rescue, D_shared, or old Contextual F1 as if they were unfinished candidate tournaments. The scientifically coherent successor should instead define a structured teacher object with explicit component roles, for example:

- measured / biologically anchored components;
- shared/global state components;
- query-local/context components;
- optional specialist/private components;
- support / abstention state;
- biological-evidence uncertainty;
- measurement uncertainty.

For every component, the machine contract should require one of:

`RECOVERABLE_FROM_VIEW`, `PARTIALLY_RECOVERABLE_FROM_VIEW`, `NONRECOVERABLE_FROM_VIEW`, `NOT_IDENTIFIED`.

Promotion should require teacher fidelity first, then student recoverability relative to the component's lawful ceiling. A biologically important nonrecoverable component must not be scored as model failure, and a predictable component must not be promoted as biology without an independent fidelity test.
