## What this contract does

This contract freezes the scientific premise that must be qualified before any real target/representation execution is authorized. It does not select a target, representation, biological dimension, estimand or numeric deciding margin.

The project distinguishes:

`observable RNA -> recoverable RNA structure -> biologically supported state -> transferable biological state -> regulatory support -> causal/interventional state`

Each transition requires its own evidence.

- **P1 Target meaning:** define the object independently of the architecture that predicts it.

### Canonical identity boundary

Real registry identifiers may define the tokenizer vocabulary while synthetic biology is allocated randomly with respect to gene symbol. In that use, synthetic signal landing on APOE, TSPAN6 or any other named gene asserts **nothing** biologically about that gene.

This creates two distinct use modes:

1. **Scratch synthetic training/qualification.** Random planted biology over real identity slots is allowed because the model has not inherited real-data-trained gene-identity semantics. Real-gene biological interpretation remains forbidden.
2. **Evaluation of a real-data-trained checkpoint.** Random reassignment of biology over real identities is **not allowed**. A checkpoint has learned identity-specific embeddings/semantics; random planting would actively make the benchmark adversarial for the wrong reason. This use remains `UNRESOLVED_REQUIRES_PROSPECTIVE_IDENTITY_SEMANTICS` until a separate checkpoint-evaluation identity contract is frozen.

This is distinct from the blocked 96-feature-to-canonical projection: no 96-feature synthetic biology is being mapped onto arbitrary real genes.
