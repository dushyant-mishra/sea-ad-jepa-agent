### 4.2 Why the target changed from coordinates to relations

Repeated attempts to define universal fixed coordinates failed donor recurrence, source transfer, correct-cell alignment, null attacks, or measurability. The surviving object became relational rather than coordinate-identical.

The relational theory freezes:

` s_i(g,h) = sign(x_ig - x_ih) in {-1,0,+1} `

with zero meaning unresolved/tied at the current measurement, not automatically biological equality.

For a fixed pair-coordinate set `P`:

`d(a,b) = [sum_p I_p(a,b) * |s_a(p)-s_b(p)|] / [2 * sum_p I_p(a,b)]`

where a prospectively frozen minimum informative-coordinate rule applies.

The scale-free anchored relation is:

`q(i;j,k) = sign(d(i,j)-d(i,k))`.

The donor is the primary inference unit. A donor agreement statistic is the fraction of resolved relations where independent molecular views agree on `q`.

Matched wrong-cell nulls keep X identities fixed and reassign Y identities only within donor×operator depth/detection-matched blocks using deterministic nonzero cyclic shifts. Each observed/null arm independently earns Y measurability; conditioning the null on observed-Y measurability is forbidden.
