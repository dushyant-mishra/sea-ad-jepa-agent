## Scientific correction 1: HVS/SEA-AD physical feature identity is not currently requalified

The recovered historical discovery-expression producer was inspected directly. Its critical assumption is effectively:

`source_feature_index -> sparse H5/H5AD physical matrix column`

The producer builds a source-address map from provenance `source_feature_index` values and then applies that mapping to sparse-matrix physical `indices` values. That is only valid if the physical column order of the authenticated matrix has already been proven to be the same feature order represented by the provenance index.

That proof is currently missing for the affected HVS and SEA-AD historical substrate.

The corrected binding requirement is:

`intended source feature identity -> matrix-specific physical feature identity -> matrix-specific physical column -> raw count slot -> canonical output column`

The next agent must not collapse those steps back into an index-equality assumption.

### Consequence

The historical 50K discovery-expression artifact can remain cryptographically authentic as bytes while still being semantically unqualified for HVS/SEA-AD gene values. The defect is semantic address binding, not necessarily byte corruption.

Therefore:

- historical HVS/SEA-AD 50K values are **not presently gene-value-qualified**;
- any TD result that numerically depends on those HVS/SEA-AD values is **replay-required** after correct physical-column binding;
- cross-source claims that include those values cannot presently be treated as fully gene-value-qualified;

## Scientific correction 2: the rich-teacher concept survives, but full realized-state point matching does not

The teacher may legitimately observe richer evidence than the student. That is not the flaw.

The flaw is requiring a partial-RNA student to deterministically point-match teacher-private realized information that is not identifiable from the student's permitted context.

Under squared-error point prediction, the deterministic optimum is a conditional expectation such as:

`E[z_T | C, q]`

not, in general, the realized rich-teacher state `z_T(T, q)` when `T` contains information unavailable to the student.

A useful conceptual decomposition remains:

`z_T = z_predictable(C,q) + z_teacher_private(T,C,q)`

plus uncertainty from biology and measurement.

Accordingly:

- rich teacher = still desirable;
- exact deterministic recovery of full teacher-private realized state = not assumed;
- component-level recoverability must be demonstrated rather than inferred;
- teacher-private information should be represented with uncertainty/distribution/abstention or excluded from deterministic point loss unless predictability is actually qualified.

Historical `D_shared` / `D_private` cannot be silently relabeled as these components. Their original semantics were tied to donor/operator/technical stability and require re-derivation before use as an identifiability decomposition.
