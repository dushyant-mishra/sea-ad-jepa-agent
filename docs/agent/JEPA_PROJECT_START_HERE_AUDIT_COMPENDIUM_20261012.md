## 1. Scientific objective

The project is building a pathology-blind JEPA/world-model target system for large-scale single-cell / single-nucleus brain data, ultimately intended to expose biologically meaningful and potentially rare Alzheimer’s vulnerability, resilience, regulatory, spatial, and perturbationally actionable programs.

The target is **not** hidden-gene imputation. The intended state is multidimensional biology learned from lawful measured evidence, with explicit separation of:

- shared/global biology;
- query-conditioned/local biology;
- relational/neighborhood biology where qualified;
- regulatory/context specialist biology where qualified;
- support and abstention;
- biological uncertainty versus measurement uncertainty;
- recoverable student biology versus teacher-private privileged biology.

Rare biology and common biology are not separate projects. Rarity is a regime/property that the same target portfolio must preserve.
