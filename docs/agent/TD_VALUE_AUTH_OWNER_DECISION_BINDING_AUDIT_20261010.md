# TD value-read authorization owner-decision binding audit

Date: 2026-10-10

Status: `PREAUTHORIZATION_AUDIT_ONLY__NO_RUNTIME_AUTHORITY__NO_VALUE_READ`

## Finding

The standalone-V2 runtime authorization gate on PR #263 binds the exact G4/G5 driver/mapping receipt bytes, implementation commit, common/G6/G7 code identities, entrypoints, schema/token/scope, and keeps biological replay / target selection / TD60 / training false.

That is necessary but not sufficient for the project governance rule that a corrected-value read occurs only after an explicit owner decision.

A technically valid `JEPA_TD_RELATIONAL_VALUE_READ_AUTHORIZATION_V2` JSON could otherwise be fabricated by someone with filesystem/repository access unless the runtime object also binds an immutable owner-decision record.

## Required future rule

No runtime value authorization may be created until after PR #263 (or reviewed successor) is canonically qualified and the owner explicitly authorizes G6/G7 integrity execution.

The runtime authorization must then include and the runtime gate must verify:

- `owner_decision_record_sha256`: SHA-256 of the exact immutable decision record bytes;
- `owner_decision_record_schema`: a dedicated owner-decision schema, distinct from the runtime authorization schema;
- `owner_decision`: exact narrow decision `AUTHORIZE_G6_G7_INTEGRITY_ONLY`;
- `authorized_preflight_result_sha256`: exact audited PR #259 driver receipt SHA;
- `authorized_mapping_receipt_sha256`: exact audited PR #259 mapping receipt SHA;
- `authorized_implementation_commit_sha`: exact canonically qualified standalone-V2 implementation commit;
- explicit false values for biological replay, target selection, TD60, and training.

The owner-decision record itself must not be generated by G6/G7 code. It is a governance artifact created only after the owner decision.

## Sequencing

1. Qualify PR #263 exact code freeze against focused tests and exact PR #259 bytes.
2. STOP and review qualification evidence.
3. If the owner explicitly authorizes G6/G7 integrity execution, create an immutable owner-decision record.
4. Only then create a runtime V2 authorization bound to that decision record plus the already frozen evidence/code identities.
5. G6 and G7 must verify both objects before any value read.

## Boundary

This audit creates no owner-decision record, no runtime authorization, and no value-read authority.
