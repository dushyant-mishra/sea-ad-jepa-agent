## The useful technical result

Historical Level-4 and discovery expression contracts specify one normalization: `z_g = log1p(10000 * raw_g / L)`, where `L` is the cell's **full source library**. Dropping query `q` from the student/teacher vector *after* this transformation retains mathematical dependence on its count `raw_q` in all other coordinates. Original full-library-normalized features and full-library-derived QC must **not** be labeled query-blind.

A candidate strict query-excluded normalization **can be computed from the existing normalized expression without a wholesale raw-count re-ETL**, if the producer really implements the documented formula and has not clipped, modified, rounded incompatibly or omitted the original query value:

```
r_q = expm1(z_q) / 10000                # equals raw_q / L
z_other_strict = log1p(expm1(z_other) / (1 - r_q))
             == log1p(10000 * raw_other / (L - raw_q))
```

`q` is used **transiently inside the trusted preprocessing adapter**, then the q scalar and original full-library-normalized data must be destroyed/withheld at the student/teacher boundary. This is not a justification for supplying `r_q`, `z_q`, original `L`, original non-query `z_other` or q-dependent QC to either model. The query-excluded denominator retains counts from other genes outside the selected modeling panel, provided the original `L` included those genes; do **not** normalize merely within the reduced model panel. Fail closed if `1-r_q` is nonfinite/nonpositive or too small for a declared numerical budget, and if the query is structurally unmeasured or ambiguously registered.

A query-only counterfactual changes `raw_q`, holds every other raw count (including unmodeled source-library counts) fixed, and asks whether **every exposed feature, query-selection decision and teacher target** is invariant. This is a computational firewall, not a claim of statistical independence: genuinely correlated remaining-RNA biology may predict `q`, and that is not the prohibited direct leakage.

### What we executed here

`teacher_target_preflight_v2.py` verifies the entire *inner* historical NPZ SHA-256, reads 1,000 CSR rows without materializing the 2.5-GB uncompressed arrays and tests two chosen observed nonzero query coordinates per row (the largest and a reproducibly random positive), with four mathematical q-only counterfactuals per choice. No new real cell, protected outcome or model checkpoint is accessed. It separately checks exact raw-count equivalence, q-exclusion under outside-panel count mass, invalid denominator rejection and PyTorch autograd leakage against raw exclusion and the inherited leaky transform.

- **1,000 historical rows; 2,000 query choices; 8,000 derived q-only counterfactual cases.** Query-proportion maximum in this bounded prefix: ~0.1918; no numerical denominator rejections there.
- Original full-library non-query coordinates changed as much as **1.2496 log units** under deliberately strong q-only counterfactuals; the original route is not invariant.
- Strict transformation counterfactual maximum numerical discrepancy in float64: **3.55×10^-15** (same observed baseline mathematically rederived).
- When both original/counterfactual log values are independently quantized to **float32**, maximum discrepancy: **1.47×10^-6**, 99th percentile **6.05×10^-7**. At **six decimal places**, maximum: **2.61×10^-6**, 99th percentile **1.28×10^-6**. These are *precision sensitivity simulations*, not a claim about Level-4 production's actual storage precision. Do **not** set a universal 1×10^-6 equality test without verifying production precision and representation.
- In a synthetic PyTorch raw-count fixture, query gradient is zero for strict pre-normalization exclusion, **−1.518** for inherited full-library normalization, and ~**1.33×10^-15** after differentiable inverse normalization (zero up to floating-point cancellation). This is a scalar computation test, not the existing V5 gradient-firewall qualification.

Independent `teacher_target_redteam_v2.py` compared the candidate adapter with *direct raw-count leave-one-out normalization* across **3,500** seeded random count vectors (including absent q, extreme expressed q and outside-panel counts) and **17,500** q-only counterfactuals. Maximum direct error `2.60×10^-12`; maximum counterfactual error `5.59×10^-11`. It also detected full-library normalization leakage in 12,068 challenged cases and caught the otherwise overlooked **count-dependent query-selection** and **all-gene depth/QC** side channels. All red-team assertions passed; none test the live current V5 implementation.

## Prospective strict teacher candidate (scientific choice still pending)

The matching objective predicts the **query-local latent molecular state**, never the hidden scalar. Same-cell T and C are biologically dependent and are not independent measurements.

Pre-filter `q` before pooling/feature engineering; if accepting the candidate inverse adapter, it must be a *trusted, independently versioned precursor* that exposes only its normalized non-q output to model encoders. Determine measured-vs-structurally-unmeasured status from the frozen operator observation registry; an observed zero is not a structurally unmeasured gene. Select eligible q from **structural support and a predeclared RNG**, not from `raw_q>0` or a rank based on query expression. Derive complementary gene views from q identity and measured support without observing q count.
