TD56–TD59 remain useful evidence that disjoint molecular views carry recurrent cell-state geometry across donors and sources, but their historical biological-specificity null is not sufficient for training authority. TD57B's wrong-cell null reassigns Y identities within donor×operator depth/detection blocks.
