Despite this, final biology adjudication was `T1_CONTEXTUAL_BIOLOGY_NOT_RECOVERED`.

Classification:

This is a direct historical warning against using target-match optimization as a surrogate for target quality.

## Large learned query-cross-attention predictor did not establish query-specific biology

A subsequent V6R5B forward-only analysis materialized:

- 1,942 primary cells / 70 donors;
- 4,785,088 primary queries;
- 177,408 literal singleton arm-query calls;
- frozen model state and no outcome-adaptive input preparation.

The latent-space correct-memory advantage was real and donor-reproducible, but biological interpretation failed:

- correct memory reduced H-space error only about 4-5% versus query-only and ~3% versus shuffled, nearly flat across programs;
- SELF-MASKED molecular reader ceiling failed at about `R2 ~= -0.015`;
- simple visible-RNA baseline recovered captured program scores strongly;
- about 95% of correct-versus-shuffled difference was cell-global in energy;
- attention normalized entropy ~= `0.998`;
- routing patterns for different queries cosine ~= `0.991`;
- program-matched memory enrichment ~= `1.0x`.

Literal singleton checks excluded batching as an explanation. Four post-metric adjudicators unanimously denied promotion. Their shared conclusion was that latent-space correction was real but biological program recovery remained unproven.

Classification:

`V6R5B_LATENT_PREDICTION_SIGNAL_REAL__QUERY_SPECIFIC_BIOLOGICAL_RECOVERY_NOT_ESTABLISHED__CELL_GLOBAL_BROADCAST_DOMINANT`

## Consequence for current target discovery

Historical evidence already falsifies several tempting shortcuts:

1. low teacher/student latent loss is not sufficient evidence of biological target quality;
2. high whole-vector predictability can be driven mostly by cell-global structure rather than query-specific biology;
3. query self-masking solves a leakage problem but does not by itself create a useful target;
4. strict donor-cross-fit residualization is not an available rescue;
5. partial-RNA student predictability must be assessed **component-wise and biologically**, not only by latent R2/cosine;
6. the target must preserve the useful query-local information already present in lawful rich representations rather than overwrite it with an easier/static objective.

This strengthens the recovered `information x conditional-predictability frontier` principle and current V3 requirement to separate target meaning from recoverability.
