## Historical principle recovered

The August 21 governed repair plan already identified the target problem as an **information × conditional-predictability frontier**.

It recorded two opposite historical failures:

- incumbent pooled hidden-state target: too much gene/address information destroyed before prediction;
- Signed-V2: retained substantially more information but asked the student to predict an idiosyncratic target not recoverable from lawful visible evidence.

Therefore target selection was never supposed to maximize teacher richness alone or student predictability alone. A lawful target had to preserve biologically meaningful information while remaining conditionally predictable where point prediction is demanded.

The same plan states that the foundation does not reconstruct unknowable missing transcript values and must express uncertainty or abstain when biological evidence is insufficient.

Its intended representation/output stack retained:

- complete gene-resolved H;
- accountable shared G/P;
- positive innovation/rare reserve;
- downstream partial-to-complete biological belief;
- program-specific effective support and visible evidence;
- separate evidence, measurement and domain uncertainty;
- abstention / insufficient-support output.

It also required complete-H preservation, partial inference, uncertainty calibration and recurrence/generalization to be gated independently.

## Important consequence

The absence of a distributional student head does **not** imply one must be invented immediately. The older dual-gate logic provides a simpler prospective path:

1. first determine target information content / teacher fidelity;
2. separately measure conditional predictability from lawful student evidence;
3. classify target components by recoverability;
4. allow deterministic student loss only on components prospectively shown recoverable enough for that loss;
5. keep nonrecoverable/partially recoverable teacher information in the richer state, but do not count exact point mismatch as ordinary prediction failure;
6. use uncertainty/abstention for underdetermined components unless a later reviewed distributional objective is justified.

This avoids prematurely adding neural machinery while still respecting the rich-teacher / partial-student identifiability limit.
