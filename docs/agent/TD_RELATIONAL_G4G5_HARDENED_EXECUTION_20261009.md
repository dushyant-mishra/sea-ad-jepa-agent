2. **Latent second blocker.** The `A_NATURAL_MIXTURE` source counts match the code's frozen `SOURCE_COUNTS` exactly: SEA_AD 22,561, NPH52 1,310, HVS 1,129. However, its non-NPH52 rows span **34** distinct H5 matrix IDs. These form a strict subset of the 35-matrix S174 freeze; the one missing is `HVS::5e9da577-f665-44af-b9b4-fa0d5ad1964d`. The check `all_35_h5_source_sha256_verified` requires `authenticated_h5 == expected_h5 and len(authenticated_h5) == 35`, and the audit hashes only the matrices that Sample A references. Two repairs are possible: the audit could byte-authenticate all 35 S174-frozen H5ADs (custody of the full freeze) while mapping only Sample-A matrices, or the expected count could change.
