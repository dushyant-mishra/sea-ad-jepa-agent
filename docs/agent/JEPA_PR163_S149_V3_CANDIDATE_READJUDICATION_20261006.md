## Candidate-by-candidate adjudication

### `T_A` — query value present in teacher

**Status:** `CLOSED__QUERY_VALUE_LEAKAGE`

Why:
- the hidden scalar reaches the teacher before contextual mixing;
- target states can therefore carry the answer being hidden;
- strong prediction would not distinguish latent-state recovery from contextualized scalar reconstruction.

S149 is not needed to close this candidate. It is already incompatible with the stated target goal.

### `T_B1` — value-blind query slot, teacher hides query only

**Status:** `PRIORITY_LIVE_CANDIDATE__S149_RETEST_REQUIRED`

Mechanism:
- the teacher receives values for measured RNA other than q;
- q identity is supplied through a value-blind slot whose value channel is a shared constant;
- q is withheld before contextual mixing;
- the teacher therefore has richer *other-RNA* evidence than the student when the student has an additional hidden set.

Why it remains scientifically interesting:
- removes the direct/indirect query-value route while preserving the central JEPA asymmetry: teacher has richer biological evidence than student;
- target may contain information not trivially reproducible from the exact student view;
- maps primarily to V3 `QUERY_LOCAL_STATE`, with a possible later structured/global context contribution only if separately demonstrated.

Load-bearing risks:
1. **Normalization leakage.** Any total/count/QC/support quantity containing q can leak q into every other token. `N_TOTAL_COUNT_INCLUDING_QUERY` is therefore forbidden for a lawful test.
2. **Address identity.** A value-blind q slot can still become a gene-prior target. Query exchangeability/address-identity controls are mandatory.
3. **Global-state shortcut.** Rich remaining RNA may let a global cell summary predict the target without query-local biology. Capacity-matched global controls are mandatory.
4. **Study/operator shortcut.** The teacher's richer RNA can encode HVS/NPH52/SEA-AD measurement composition. Deciding evidence must be estimated within observation process and then transported across processes.
5. **Teacher-easier-than-student asymmetry.** B1 can appear strong because the teacher hides only q while the student sees less. This is not automatically a defect—the JEPA premise is richer teacher evidence—but target-object recoverability and incremental information must be reported separately.

Current interpretation:
- strongest surviving PR #163 construction for a first lawful real-RNA discrimination;
- **not selected** and not biologically qualified.

### `T_B2` — value-blind query slot, teacher hides the full student mask

**Status:** `LIVE_COMPARATOR__HIGH_SELF_COPY_COLLAPSE_RISK`

Mechanism:
- q remains value-blind;
- teacher and student are conditioned on essentially the same visible molecular evidence.

Strength:
- removes teacher/student evidence asymmetry as a confounder.

Primary concern:
- target can become a smoothed EMA transformation of exactly the student's own input. A candidate may therefore look predictable while adding little or no privileged/query-local information.

Role in current tournament:
- valuable as a stringent scientific comparator to B1;
- should not receive incumbent preference simply because it is symmetric;
- must pass query-exchangeability, identity, capacity-matched global, and target-object incremental-information tests.

### `T_C` — whole-block value-blind target

**Status:** `LIVE_BUT_BLOCKED_PENDING_S149_SAFE_BLOCK_PROVENANCE`

Why:
- withholding an entire neighborhood/program before teacher mixing is conceptually compatible with value blindness;
- it potentially maps to V3 `PROGRAM_STATE` or `STRUCTURED_COMBINED_STATE` rather than a pure single-query state.

Blockers:
- target meaning depends on how the block/neighborhood is defined;
- any block derived from pooled covariance/detection/topology is now S149-risk;
- historical masking/block qualification was itself unresolved;
- block-level construction can amplify program identity or source/operator modules.

Do not run T_C as a deciding candidate until the block construction is shown to be prospective and either source-independent or fit within lawful TRAIN strata with held-out transport.

### `T_D` — residualized modifier

**Status:** `DIAGNOSTIC_ONLY__DO_NOT_TREAT_AS_RESCUE`

Residualization may remain useful as a diagnostic view, but historical V6R5B already showed donor-cross-fitted residualization did not rescue the desired molecular/query-local target: improvements were predominantly global while molecular recovery remained weak.

Do not promote `T_D` into an untested primary target family merely because S149 adds another confounder.
