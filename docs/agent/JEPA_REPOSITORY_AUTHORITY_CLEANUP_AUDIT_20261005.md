## Repository-scale hygiene finding

During this audit GitHub reported 167 open PRs and branch listings spanning more than 300 branches. Branch/PR count alone is not grounds for deletion because many lanes carry unique evidence.

Use these classifications before any closure/deletion:

- `CURRENT`
- `SUPERSEDED`
- `HISTORICAL_EVIDENCE`
- `CUSTODY_ONLY`
- `INCOMPLETE_STOPPED`
- `DEFERRED`

## Cleanup rules

- Never delete an artifact solely because a newer handoff exists.
- Never rewrite scientific result bytes to make history look cleaner.
- Correct current routing and add supersession/retraction notices.
- Close superseded PRs only after confirming their unique evidence is preserved and their successor is named.
- Delete branches only after exact ancestry/evidence-preservation review.
- Infrastructure PASS must remain distinct from biology PASS.
- Checkpoint existence must remain distinct from checkpoint scientific authority.
