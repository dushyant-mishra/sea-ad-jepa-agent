# JEPA cross-modal specificity / identifiability boundary

Date: 2026-10-07

Status: `NO_QUALIFIED_CROSS_MODAL_BIOLOGICAL_SPECIFICITY_GATE__REAL_CORRESPONDENCE_REMAINS_UNOPENED`

This checkpoint consolidates historical multimodal gate results. It does not authorize opening real biological RNA–ATAC correspondence, target selection, Stage A, multimodal training or production training.

## Scientific question

The relevant question is not simply whether RNA and ATAC correlate in the same nucleus. It is whether a prospectively frozen cross-modal statistic can distinguish biologically shared state from plausible shared technical / nuclear-quality / handling state.

## Historical sequence recovered

1. The project established an exact same-RNA semantic-twin limitation: if two worlds have the same observable RNA views and metadata but one latent is called biology and the other unmeasured capture, no observable-only statistic can distinguish the semantic labels. The correct same-RNA terminal was therefore an identifiability limitation, not a statement that the real signal is technical.

2. The project pivoted to orthogonal modality evidence, especially RNA + ATAC, with explicit negative families:
   - independent null;
   - measured technical shared state;
   - hidden generic nuclear-quality state;
   - handling/exAM-like shared nuisance;
   - planted biological shared state.

3. The first cross-modal probe was later classified invalid/insufficient and carried no scientific biological verdict. Real biological correspondence remained unopened.

4. Synthetic multimodal mechanics improved materially later:
   - a 40K-region ATAC layer;
   - real genomic coordinates;
   - same-cell pairing;
   - 250 kb cis windows;
   - TSS distance and decoys;
   - sparse target-linked regulatory structure;
   - separation of sparse target-linked biological signal from dense depth-correlated technical signal.

5. Those structural improvements did not produce a qualified biological-specificity gate:
   - S126 ATAC observer SNR remained unqualified; module-score R2 was near zero under excessive noise;
   - V53–V57 regulatory specificity tournaments were negative / underpowered;
   - V58 retained a semantic-twin non-identifiability warning: synthetic worlds can satisfy mechanical criteria while the semantic assignment remains unidentified.

## Important inference boundary

Multimodal agreement can rule out some nuisance explanations that are assay-specific. It does **not** logically prove biological identity against an unrestricted latent factor that jointly affects both modalities.

Therefore a future observational gate must state exactly which nuisance family it has qualified against. It must not use a universal label such as `BIOLOGY_PROVEN` unless an identification argument supports that semantic claim.

A scientifically defensible later result could look like:

`CROSS_MODAL_STATE_SUPPORTED_BEYOND_FROZEN_MEASURED_TECHNICAL_CONTROLS__LATENT_SHARED_NUISANCE_NOT_FULLY_IDENTIFIABLE`

rather than claiming unrestricted biological proof.

## What would count as progress

Before opening GSE214979 or any protected correspondence, prospectively freeze:

- exact statistic / geometry;
- direct peak-level or otherwise independently justified ATAC representation;
- RNA representation being evaluated;
- allowed QC variables;
- residualization / matching rules;
- donor/cell/library weighting;
- negative-control generators;
- positive-control generator;
- threshold / decision rule;
- seed / replicate precision authority;
- code and data roots;
- exact nuisance family against which specificity is claimed.

The gate must reject measured technical correspondence and must explicitly test whether plausible latent shared-nuisance worlds can be semantic twins of the planted biological world. If they can, record the identifiability ceiling instead of tuning a threshold.

## Development-data recommendation

Use development-exposed paired data (for example the already exposed SEA-AD paired subset) for technical pipeline/QC mechanics where lawful, while preserving cleaner GSE214979 biological correspondence for a later frozen one-shot test. Even in development-exposed data, do not use target-specific biological outcomes to tune the technical gate.

## Claim-ladder implication

Stage A remains capped at `RNA_REPRESENTATION`. A future transition to `TRANSFERABLE_BIOLOGICAL_STATE` or `REGULATORY_SUPPORT` must bind both:

1. the exact cross-modal evidence result; and
2. the exact nuisance/identifiability scope that result can exclude.

Observational RNA–ATAC concordance alone cannot establish causality.
