## What actually changed

R1–R12 produced a genuine *measured RNA anchor* for student prediction but repeatedly exposed its sparse molecules, unstable normalization and lack of independent biological fidelity. R11/R12 added increasingly detailed protections without executing the independent endpoint. This R13 work changes the experimental bottleneck: a **working leave-one-donor-out paired-multiome teacher-fidelity evaluator** and a quantitative donor-power comparison for external cohorts. The evaluator has only been executed on deliberately generated synthetic RNA and chromatin features; no reserved patient ATAC values were opened.

The scientific sequence is now: preserve the existing explicit target as a **developmental measurement anchor**; freeze a teacher's RNA-only query-conditioned state, compare its predictions of independent same-nucleus chromatin against a *linear readout of precisely the same RNA plus identical technical nuisance features*, and only then determine whether to advance a single teacher, shared multi-head teacher or independent team. Student training on a qualified latent target follows; it is not a substitute for teacher fidelity.

## The existing target — retained without misnaming it biology

Use the existing R8 source (`JEPA_R8_STRUCTURED_TARGET_CONTRACT_20260926.py`), **do not relabel the target or change its bytes**. For a query q, its context is four non-query partner counts observed in the same cell; reported measurement includes (a) log1p program activity relative to eight fully disjoint reference genes, (b) four-dimensional regularized centered-log-ratio composition when activity is nonzero, and (c) structural support and approximate molecule-sampling uncertainty. Queried count is excluded from the measured anchor even if a richer *teacher encoder* can observe it. Student gets neither q count, partner panel, reference panel, their descendant denominators, nor unobserved modalities. A zero reference causes **abstention**, not zero imputation. This is a real computational prediction target, not proof of underlying biological state.

For developmental interpretation only, R8 had APOE→APOC1/ABCA1/GPNMB/TREM2, P2RY12→TMEM119/CX3CR1/GPR34/C1QA and HLA-DRA→CD74/HLA-DPA1/HLA-DMA/IFI30. R8/R10 observed only 361 labelled microglia and two MG measurement operators; P2RY12 and HLA-DRA support remains too thin to qualify single-cell biology. No panel in this report is newly selected using external ATAC outcomes. The teacher's separately learned query-conditioned latent residual must demonstrate biology beyond the observable RNA anchor, technical-only, q-only, generic-cell and same-RNA linear controls.

## Outcome-blind analytical sensitivity — a consequential negative finding

`jepa_r13_external_validation_power.py` implements exact **idealized two-sided paired noncentral-t power** for the *donor-level improvement over same-RNA linear*, and cross-checks it against independent-donor Monte Carlo. There is **no actual ATAC outcome in the inputs**. A three-/six-contrast Bonferroni grid is illustrative, not prospective scientific authorization. With power 80% and alpha=.05, effect size d is the *mean per-donor model improvement divided by the across-donor SD of that paired difference* (not raw R²); observed distribution and residual correlation are unknown.

| Cohort | Independent donor n | d for 80% power, one primary contrast | d for 80% power, six contrasts |
|---|---:|---:|---:|
| Morabito unpaired | 18 | 0.701 | 0.915 |
| Anderson matched multiome | 15 | 0.778 | 1.029 |
| Early-onset multiome | 9 | 1.067 | 1.492 |

Even in this optimistic simple model, a moderate standardized d=.5 gives 52%/44%/26% power for 18/15/9 donors at uncorrected alpha=.05; with six contrasts the 18-donor estimate is only 23%. Actual leave-one-donor-out with nested high-dimensional estimation, 2+ biological programs, donor heterogeneity and tiny per-donor MG populations could be worse. Large nucleus counts cannot compensate for a small **independent donor** count. **Prioritize one scientifically defined primary query/program contrast and a subsequent genuinely independent replication**, not six powered biological claims from 15 donors. No numerical decision threshold is declared approved in this package.

## Executed evaluator — not a sketch

`jepa_r13_paired_multiome_evaluator.py` is a reusable *read-only* Python evaluator for true matched same-nucleus RNA/ATAC and a **pre-frozen RNA-only teacher representation**. It computes donor-held-out R² for (1) technical-only, (2) same-RNA linear with train-only PCA, (3) frozen teacher state + technical, and (4) teacher+same-RNA+technical. The principal diagnostic is the **per-donor paired improvement of arm 4 over arm 2**. Models, RNA PCA, scales and target-reference means are fit *inside each leave-one-donor-out training fold*; every donor gets equal summary weight. Synthetic fixtures challenge whether the metric detects a nonlinear RNA-derived representation that genuinely explains an independently measured modality beyond a linear RNA readout, while refusing false same-donor nucleus matching and unauthorized real outcome opening.

**Known limitations intentionally surfaced:** a fixed SHA field/boolean is not external source attestation; this does not verify a neural teacher's upstream training lineage or prove no prior ATAC leakage. `synthetic_fixture=True` is a test-only pathway, not a security barrier against a malicious caller. Real execution requires independent prospective provenance and authorization **outside this helper**; its permissions default off. The synthetic planted nonlinear biology is an engineered fixture, not a biological measurement, proof of causality or result about APOE. The evaluator measures predictive *cross-modal association*, not causality or precise regulatory edges.

The first R13 implementation FAILED its positive synthetic test because scikit-learn flattened a single-output prediction and NumPy broadcast it into a 60×60 error matrix. The original failure signature and correction are preserved in `JEPA_R13_INITIAL_FAILURE_NOTE_20260926.md`, with original tool execution in this chat. A strict `reshape(y[te].shape)` fixed the score; an explicit two-outcome regression control now prevents recurrence. This is an actual false-negative/false-result bug that previously would have allowed fabricated huge negative R². The noncentral-t implementation also encountered `scipy.stats.nct` producing NaN in an astronomically small opposite tail; its handling is now explicitly bounded and cross-checked by seeded donor-level simulation.

**Final test state: 21/21 executed R13 tests passed**, 8 prospective power and 13 evaluator tests, no original ATAC opened. Original R9/R12 checks remain distinct research evidence; passing R13 does not transform synthetic diagnostics into current-V5 executed critical-test authority.
