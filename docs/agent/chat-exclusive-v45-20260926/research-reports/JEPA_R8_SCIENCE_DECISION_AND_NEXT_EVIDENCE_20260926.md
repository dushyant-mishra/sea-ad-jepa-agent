# JEPA R8 — teacher target construction, matched-denominator falsification and scientific decision

**2026-09-26. Historical developmental research only. Not current FULL104 science or training authority. No protected outcomes inspected.**

## Decision in plain scientific terms

We have now specified and physically instantiated a **measured developmental query target** with separate program activity, composition, support and approximate molecule-sampling uncertainty. This is a genuine *target object*—the teacher could compute its observed components directly from richer same-cell original RNA, and a student could be trained to predict them from complementary RNA. It is **not yet an independently validated biological latent state** or a fully qualified teacher model. Both q-visible and q-excluded rich teachers may be compared against this *fixed measured anchor*. We must not confuse an accurate prediction of that anchor with the existence of biology beyond same-assay coexpression.

The R8 test finds one repeatedly positive **APOE-associated developmental prediction signal** that survives removing the 700 student genes from the target reference. P2RY12 and HLA-DRA programs do not consistently beat the technical comparator. Low single-cell count support and absence of independent RNA/ATAC or protein evaluation prevent scientific qualification. Accordingly, **no architecture winner, no final biological target, no FULL104 training approval**. More synthetic guards or more teacher networks would not resolve this missing evidence.

## Exact measured target object

For original same cell `c` and canonical queried gene `q`:

* A prospectively named, measured four-gene, **non-query** contextual panel `G_q`. No member may be unmeasured in the cell. The three *exploratory historical* panels are APOE: APOC1/ABCA1/GPNMB/TREM2; P2RY12: TMEM119/CX3CR1/GPR34/C1QA; HLA-DRA: CD74/HLA-DPA1/HLA-DMA/IFI30. Original current-identity Ensembl-address index is read from the exact historical calibration archive, never symbol-aliased silently. These gene lists are motivated hypotheses, not validated programs.
* A **disjoint reference panel** or disjoint complement to calculate an activity coordinate `a(c,q)=log1p(10000 * sum_{g in G_q} UMI(c,g) / sum_{r in R_q} UMI(c,r))`. `R_q` excludes all queried genes, all candidate partner and readout genes and the student panel. A fixed eight-gene developmental reference variant uses RPLP0/EEF1A1/PGK1/HPRT1/PPIA/RPL13A/GUSB/SDHA, observed in the historical microglia operators. In this particular dataset, only 271/361 microglia have nonzero total reference counts; the other 90 **abstain**, not zero-fill. These genes are NOT claimed to be stable across operators or activation states. A broader fold-specific disjoint-reference control was tested separately. **The exact final size-factor method remains scientifically open.**
* When `sum G_q > 0`, composition is the four-dimensional centered log-ratio of Dirichlet-regularized `(UMI_g+0.5)/(sum G_q+2)`; the CLR components sum to zero. When all four genes are measured zeros, activity may be zero, but **composition is undefined** and must not be represented as a genuine zero vector. If a gene is structurally unmeasured, or if the required reference is absent/zero, that component **abstains**.
* Record partner counts, reference counts, original cell/source lineage and approximate molecule-sampling standard deviations as **uncertainty metadata**, not as self-certified true biological uncertainty. Measured target values do not include the query count. A q-visible teacher may additionally observe the queried count for its *separately evaluated latent context*, while the measured anchor itself remains q-count-invariant. A q-excluded teacher is the direct comparison. Student must not receive query count, teacher panel, reference panel or descendants of forbidden measurements in its input preprocessing.
* Proposed latent world-state extension: a learned query-conditioned residual representation from richer same-cell RNA must demonstrate additional independently measured biology **beyond** this explicit observed anchor, query count alone, generic cell state and technical-only models. Its latent dimensions, alignment, losses and weights remain UNSELECTED until an independent biological falsifier exists. Multiple specialist teachers can be compared only on the exact same anchor and reserved biological endpoints.

## Exact R8 physical experimental scope

The original 410,278,055-byte historical calibration ZIP was rehashed to SHA256 `07748d5bd21fe0857ccad3002fba3946d1791d25898b841d41056a3707117444`. Developmental expression rows come from the physically extracted original discovery archive, using existing R1–R7 cache; original logarithmic values are inverted to integer UMI counts with a maximum conversion error gate. Microglia: **361 cells / 50 donors / 2 microglia operators**. The whole 1,561-cell subset spans 15 operators, but claims of microglial 15-operator generalization would be incorrect. The same historical subset has now been explored many times, so all confidence and model-selection claims are descriptive only.

The R8 pilot uses five donor-disjoint test groups (all 50 donors held out once), 32 training donors and eight validation donors per fold; fixed-size 700-gene complementary RNA selected only on training donors; three independently masked training views and a separate masked test view; train-only PCA-32 and ridge; operator and **student-visible** technical baseline. R8 did not fit a JEPA neural teacher, access reserved ATAC outcomes, inspect protected FULL104 results or produce clinical/perturbational conclusions.

The broad-reference and 700-gene-disjoint comparison uses **the same 361 microglia and held-out fold identities**. Removing the student genes changes the activity definition, not just a harmless implementation detail. The eight-gene-reference comparison is additionally affected by its **90 abstentions** and differs in normalization composition; do not interpret the changes as a pure isolated leakage effect. A planted query-count counterfactual demonstrates that the measured anchor does not use the queried count, but no such check proves biological validity. In the fixed eight-gene control, APOE beats its technical baseline in four of five folds and P2RY12/HLA-DRA do not. The other two query programs do not demonstrate robust student-predictable activity.

Split-half measurement repeatability is only a **single simulated partition of the same original molecules**. It retains cell-level technical effects and does not estimate independent biological reproducibility. Among cells with positive full-panel counts, the conditional activity half-count correlations can be substantially lower or negative; selection on observed positivity introduces additional interpretive bias. Composition diagnostics are restricted to 134/95/117 cells (APOE/P2RY12/HLA-DRA) with **both** partitions positive—zero-count composition is not a valid biological measurement.

R7's separate held-out-RNA biological-program challenges produced negative teacher-readout R² for all three programs on this underpowered cohort. R8 did **not** rerun, replace or silently erase those findings. No R8 student performance can overturn an unqualified teacher-only biological-fidelity result.

## What is now settled, and what cannot be settled from this dataset

**Settled engineering/research:** real same-cell measured target semantics; disjoint query/partner/reference/student input roles; support-aware abstention; q-visible teacher need not leak q into measured anchor; activity is distinct from within-program composition; low-count uncertainty is unavoidable; donor-disjoint sample mechanics; a matched 700-gene denominator overlap challenge and fixed separate reference challenge; no generic RNA tournament proxy can claim a biological architecture winner.

**Not scientifically closed:** which exact gene program and query scope is real; which size factor is stable under perturbations, disease or variable capture; actual teacher latent-state fidelity; use of the queried scalar to improve that latent state; independent donor-/population-level chromatin or independently matched same-cell protein validation; any cross-operator generalization beyond 2 historical microglia operators; V5 prospective target approval; current 33-root physical closure; masking scientific approval; real FULL104 training permission.

The necessary external benchmark remains in [Lane D PR #164](https://github.com/dushyant-mishra/sea-ad-jepa-agent/pull/164): original GSE174367 RNA/ATAC resources were inventoried, but RNA and ATAC nuclei are **not cell-paired**. A valid evaluation must reserve never-trained-on ATAC, freeze donor/sample/feature and confound-control matching, retain RNA/ATAC measurement-level independence rather than falsely claiming independent donors, predeclare reproducible accessibility readouts and comparisons, and meet Lane D's outstanding prerequisites before any outcome read. Using RNA-derived Stage75F hypotheses or the same ATAC data to train and validate would make the benchmark circular. No such benchmark was executed here, and no invented ATAC result is supplied.

## Architecture and existing pipeline integration decision

Keep **a single rich teacher** as the capacity-matched reference, but **do not crown it** on this RNA-based test. The shared multi-head and independent specialist teams remain conditional alternatives only if they preserve reproducible evidence missing from the rich reference. V43 support-aware target fusion provides research-only same-cell routing and abstention. V5 original `TargetConstructionAuthorityV1` *forbids teacher query scalar*, so supporting a possible richer q-visible teacher would require a **versioned, reviewed successor**, not patching historical source; preserve original EMA, optimizer-step proof, dynamic protected registry, original mask source and RNG root tests, exact-source JUnit evidence, and atomic checkpoint patterns. Add branch-aware source/gradient/optimizer and EMA coverage only if selecting multiple independently parameterized networks. DO NOT install candidate R8 outputs into any current-V5 authority root.

## Minimal path to scientific completion

1. On independent, **development-only** data with enough microglia per donor/operator, first qualify measured program stability (including targeted-depth/capture control and honest support masks); a target that fails measurement reliability cannot be improved merely by neural distillation.
2. Freeze one or more **independent biological falsifiers**, especially a separate-nuclei chromatin-accessibility evaluation for population-level relationships (not cell-level labels), and, if genuinely available, paired protein/CITE-seq or same-cell multiome for cell-level validation; check data lineage and shared-cohort leakage before viewing outcomes. A null or unavailable independent evaluation means *no qualified biology target*.
3. Compare a rich q-visible teacher, the q-excluded rich teacher and a single simple non-neural reference at **fixed measured target**, using donor-matched biology/technical controls. Only if a teacher preserves independently validated additional information should a student and then a specialist teacher team be compared.
4. Record a scientific target approval **only if those preregistered biological tests succeed**, then version the target-construction and topology/receipt contracts and satisfy outstanding 33-root governance before current FULL104 training. No historical pilot success can substitute for this step.
