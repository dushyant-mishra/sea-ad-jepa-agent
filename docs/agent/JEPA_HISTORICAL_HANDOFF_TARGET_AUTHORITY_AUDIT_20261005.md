## Reconstructed target / representation decision chain

### 1. Early target-family causal tests: T0 / T1 / TCTX

`docs/agent/ACTIVE_STATE.md` records three corrected reduced six-IPB runs, with matched initialization/cells/masks/RNG and no anchor.

- T0 block-mean complete-H mean R2 delta: -0.07663.
- T1 full-gene H_g complete-H mean R2 delta: -0.09387.
- TCTX query-self-masked H_g complete-H mean R2 delta: -0.09432.

All three remained hypotheses, not production winners.

The subsequent real production forward-only gate used 446 FOUNDATION TRAIN cells, 149 donors, 42 operators and 41,238 addresses with zero optimizer/EMA updates. It found:

- T1 conditional target row R2 0.9114 vs identity-only 0.9105.
- TCTX conditional row R2 0.9595 vs identity-only 0.9591.
- Three scoped critics returned STOP / STOP / STOP.

Conclusion: no T0/T1/TCTX candidate qualified for a causal encoder experiment. Gene/address identity explained essentially all of the impressive T1/TCTX row predictability.

### 2. Static/context decomposition

The next gate explicitly decomposed H into static address geometry and contextual increments. Context retained some biological information, but incremental evidence over identity remained tiny. Decision: STOP.

At this point the named next action was strict donor-cross-fitted per-address centering/residualization of H.

### 3. V6 -> V6R4 predictor / query-address diagnostics

The project then ran a sequence of frozen-encoder diagnostics rather than jumping directly to encoder training:

- query cross-attention to visible states;
- optimization-validity repairs;
- address-oracle / architecture-semantic checks;
- balanced address exposure;
- exposure-dose diagnostics;
- address-keyed predictor diagnostics.

These experiments showed that H strongly carries address identity, that query-address exposure was sparse, and that predictor memory could yield small improvements without establishing contextual biology. They did not authorize encoder/EMA training.

### 4. V6R5B decisive contextual-biology + residual-target adjudication

This is the key reason an August-21 "go run donor-centering" rollback is stale.

On 1,942 FOUNDATION-TRAIN cells / 70 predictor-nonfit donors and 4,785,088 frozen queries, the incumbent memory benefit was mostly cell-global and did not establish contextual biology.

The project then executed the one authorized strict donor-cross-fitted per-address residual-target intervention. On supported rows it produced large numerical H-error reductions, but:

- correct-minus-query became ~97.8% global;
- correct-minus-shuffled became ~99.89% global;
- attention entropy/query cosine became ~0.99983 / 0.99969;
- molecular R2 remained negative;
- rare5 remained near chance.

Terminal verdict: `RESIDUAL_TARGET_DOES_NOT_RESCUE`.

Authorized successor at that point: bounded address-selective predictor-capacity / target-family redesign. No encoder/EMA training.

### 5. PROD41K T1 historical run

A production 41K T1 run later completed 205 bounded updates after an earlier pre-u1 pandas collision was repaired. Final loss decreased, but the run remained optimization-incomplete and teacher biology was not qualified. On untouched oracle donors, no continuous rich-H endpoint produced a wholly positive donor CI versus u0.

This lineage is historical evidence only. It is not a current trained biological-model authority.

### 6. FOUNDATION corpus discovery reset

The project paused further T1 training/materialization decisions and audited the lawful fit-104 corpus. The old 3,292-cell cache was found grossly distorted relative to the 4,553,407-cell, 104-donor, 42-operator corpus. Local expression geometry was seed-sensitive. This correctly moved the project away from treating the old cache/checkpoints as production authority.

### 7. FULL104 expression / dimensional-authority program

The FULL104 expression interface was later verified. Phase-2 state-derivation work was explicitly ordered around shared/private state derivation, D_total/capacity, standardization, and direct molecular basis/ridge analysis. This is important because it preserves the distinction between neural width and biological rank.

Historical values such as 160 were never production dimension authority. `d_gene`/token width is model capacity; biological dimensions such as D_shared/D_private/D_total/D_obs require separate empirical authority.

## Q3 wording correction

The V76 audit correctly rejects `cell_state` as an already-qualified global scientific state. However, the strongest wording that it is completely "unconstrained" should be interpreted carefully.

The cell token participates in encoder self-attention and its final state is also available to the predictor, so gene-block loss can propagate through pathways involving it. What is not established is that the objective IDENTIFIES the final cell token as a sufficient or unique global biological state.

Current classification:

`CELL_STATE_AS_DESIGNATED_GLOBAL_BIOLOGICAL_STATE = UNQUALIFIED / NOT_IDENTIFIED_BY_OBJECTIVE`

This nuance does not reopen state qualification. Target authority is upstream.
