- BASE q withheld and measured-zero distinct from structural absence; candidate may only `NOT_ESTIMABLE` if original support/depth makes it genuinely impossible.
- Counterfactually increase withheld q count **and** fixture whole-row source mass; all BASE view bytes must remain identical while RICH query bytes change.
- BASE Task5 fixture accepted with explicit `externally_authenticated=False`; RICH **must refuse** when q count exceeds projected BASE depth under original physical-library constraint (already-known schema issue).
- Hidden off-ledger-only mass -> changed BASE depth (known PR478 weakness); fake source label accepted by source-unauthenticated fixture; q-in-BASE accepted by the fixture because q not part of producer issuer contract. Each results in **NO SOURCE QUALIFICATION**, not a bogus successful issuer.
- Query swapped to a different address changes fixture view (mechanical responsiveness, **not** learned wrong-query specificity); outside-base collision returns `NOT_ESTIMABLE`.
