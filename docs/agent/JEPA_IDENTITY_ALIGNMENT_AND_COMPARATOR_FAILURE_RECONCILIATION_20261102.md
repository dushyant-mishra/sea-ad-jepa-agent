## 1. Gene-feature identity recovery: pre-Stage81A2R NPH/cross-source results

**Problem:** An earlier gene semantic layer was insufficient to prove that a source feature/row and a universal molecular address were the *same gene*. NPH52 in particular included source-native identifiers, historical aliases and identifier-poor records. A numerically correct comparison can still compare the wrong molecules if raw feature indices or display symbols are treated as stable universal gene identities. This is **not evidence** that every source-native experiment was wrong.

**Original impact and disposition:** The October 13 historical audit (`docs/agent/JEPA_GENE_IDENTITY_RECLASSIFICATION_AUDIT_20261013.md`, blob `3cc53abf5ea8655d8f283d40f235927386ba0f61`) identified the historical optimum among **2/4/8 teacher views** as `GENE_IDENTITY_PROVENANCE_UNRESOLVED`: it has no active architecture-selection authority and may be prospectively replayed **only if still material**. Other old NPH/cross-source per-gene-semantic claims without proof against the repaired registry are likewise non-authoritative, **not** automatically wrong in numerical value. Do not describe this audit as having measured score deltas for every old baseline.

**Physical/source repair:** Stage81A2R used source rowData and exact Ensembl/HGNC/historical identities, preserved unresolved/ambiguous source-native evidence, produced **40,422** current exact + **773** legacy exact + **43** source-native anchored = **41,238** universal molecular addresses, preserved **2,010** nonuniversal identities (2,009 identifier poor, 1 ambiguous), and reported source/matrix canonical collision evidence rather than silently merging it. Early recovery found **11,435** within-matrix collision rows; a later August loader archive audit enumerated **11,449** collision pairs across its main+supplemental inventories, still requiring source-specific proof. Counts refer to different inventories; do not substitute them. `scripts/v4/foundation_materialize_nph_discovery_sample.R` explicitly uses the **source_feature_index -> molecular_address_index** join, excludes collision rows and fails on noninjective mapping before writing 41,238-column sparse shards.

**What was demonstrated after repair:** The October 13 audit checked 41,238 program-weight molecular address IDs against the calibration registry and found their **order identical**. The 50,000×41,238 expression NPZ contains no embedded gene labels; its column interpretation therefore depends on that external registry binding. V44 and the local 41K smoke work are accepted only as **repaired-address-bound exploratory** evidence, not production FULL104 biological authority. NPH52 physical reader-fit cohort firewall is independently established, but **real NPH52 hidden-query issuance remains blocked** under later #509/#513 source alias and off-ledger leak restrictions.

## 2. FULL104 cell-row scrambling: a distinct defect that invalidated donor-heldout linkage

**This was a cell-row/donor join error, not a demonstrated shuffle of gene columns.** The rejected September 17 pass1 associated `cell_donor` using block iteration order rather than authoritative `selection_row`. In a 12-block adversarial verification, 0/12 matched selection_row, 12/12 matched block position; the original aggregation still looked arithmetically plausible because its totals were order-invariant. Thus any analysis relying on correct *cell → donor → held-out outcome* linkage from the invalid pass1 could not claim legitimate donor-held-out validation or comparator scores; bias direction was **not proven** in the original independent review (do not say "it necessarily inflated").

**Repair:** [PR #31](https://github.com/dushyant-mishra/sea-ad-jepa-agent/pull/31) rebuilt physical pass1 on `selection_row`, covering **4,553,407 cells, 104 donors, 42 operators, 41,238 addresses, 8,915 blocks**. It introduced block-order/row-order scramble invariance plus a regression reproducing the old defect and requiring a refusal. [PR #32](https://github.com/dushyant-mishra/sea-ad-jepa-agent/pull/32) repaired review issues and reproduced pass1 **byte-for-byte** at SHA-256 `37f79e49f11364daa487ad9e5a5680f72378daf338852765d2f52e1e98d90ba1` from a clean source head. The September 17 artifact is preserved as `INVALID_FOR_CURRENT_ROLE`, not reused as baseline/validation authority. The corrected aggregate's **17,053** all-fold target eligibility remains a distinct screening result, not a target winner.

## 3. GSE311359 BIN1 guide-feature identity collapse: genuinely wrong guide/comparison units

**Problem:** An older perturbation producer used human-readable guide *display name* as a dictionary/pseudobulk key, collapsing the **three distinct BIN1 cis-regulatory-element capture features** under a single `BIN1` label. There were **381** guide feature rows but only **379** distinct display names. This compromised BIN1 guide/sample counts and claimed independent guide identities; the 70-target V1 headline was not a clean validation score.

**Repair:** [PR #92](https://github.com/dushyant-mishra/sea-ad-jepa-agent/pull/92) added an independently tested fail-closed STOP and preserved V1 evidence. [PR #118](https://github.com/dushyant-mishra/sea-ad-jepa-agent/pull/118) recovered exact distinct source IDs `BIN1_enh_1`, `BIN1_enh_2`, `BIN1_enh_2_AS` from authentic `features.tsv` column 1; source feature IDs/names/order agreed across seven libraries. [PR #121](https://github.com/dushyant-mishra/sea-ad-jepa-agent/pull/121), `analysis/therapeutic_perturbation_etl/PR118_AUDIT_RESPONSE_20260925.md`, physically rebuilt **feature-ID-keyed V2**: old V1 contained **14** BIN1 rows claiming cells but having zero counts; V2 has **0**. All **2,434 non-BIN1 units** reproduce exactly with zero count/cell disagreements; the three cis elements stay distinct. [PR #126](https://github.com/dushyant-mishra/sea-ad-jepa-agent/pull/126) carried forward versioned curator/readiness assertions and hostile tests. **Physical ID-keying is repaired**, but protospacer/engagement, causal cis-target identity and independent experiment replication remain different questions; do not promote to real response benchmark truth just because ETL/CI is green.

## 4. Morabito crosswalk PAR_Y/symbol collisions

[PR #175](https://github.com/dushyant-mishra/sea-ad-jepa-agent/pull/175) audited all 41,238 addresses against physical GSE174367 RNA/ATAC. It found **216 symbol-collision rows and 45 `_PAR_Y` stable-ID collisions**. An initial implementation treated `_PAR_Y` as opaque and incorrectly dropped the Y copy; a repair at `0012b0ca` recognized shared base IDs, increasing **ambiguous mappings from 3 to 35** before downstream use. This makes exact uniqueness/assayed-but-undetected/unmeasured state essential for valid assay comparisons. This is a **Morabito crosswalk repair**, not proof that earlier FULL104 baselines were all recomputed.

## 5. F1/QID comparator mismatch and wrong evidence-mask construction

These are additional **comparison-definition errors**, not direct proof of gene-ID column scrambling.

- The original QID "wrong-query" claim substituted a matched-null *cell state* against a true teacher while preserving query identity. `docs/agent/JEPA_HISTORICAL_AUDITS_INDEX_20260915.md` identifies this as **`matched-null state intervention != paired-wrong-query intervention`**. The earlier wrong-query interpretation has **no restored authority**.
- The original F1 evidence-mask implementation selected the first measured feature indices at a rounded percentage and did not exclude the queried feature. [`F1_EA35_REPAIR_RESPONSE_20260907.md`](F1_EA35_REPAIR_RESPONSE_20260907.md) records the correction: `E={measured scalar addresses except q}`, SHA-256(seed, row locator, q, j)-ranked deterministic address order, `floor(p*|E|/100)` nested evidence and all E for the rich teacher. A 14-test suite includes an old-rule negative control.
- The same F1 repair bound the donor-distinct matched-null *source values* to authentic source identities while preserving recipient measurement masks, query identity, source/operator context, and provenance digests. It **does not** equate a matched-null source-cell perturbation with a wrong-query contrast. This code is mechanics-tested only; **real F1 remained unauthorized**.
