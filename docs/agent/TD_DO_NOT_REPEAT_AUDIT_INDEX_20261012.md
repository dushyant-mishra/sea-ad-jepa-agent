## Rule for reopening history

A historical audit may be reopened only if one of these is true:
- a current artifact hash contradicts the historical receipt;
- a later audit explicitly supersedes the historical interpretation;
- a newly discovered provenance/custody defect directly affects the decision-bearing result;
- the new scientific question is genuinely different and requires a new prospective estimand.

"I do not have the old chat context" is **not** a valid reason to repeat an audit.
