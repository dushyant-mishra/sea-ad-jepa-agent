## 4. Central missing demonstration

The most important unresolved integration question is whether one realization can travel through the complete scientific chain while preserving data identity, evidence rights, hidden-truth separation and legitimate authority.

The intended chain is:

**Biological generator → observation producer → provenance-bound CaseBundle → common scientific executors → independently qualified gate results → Target Qualification Bundle → trusted TargetPortfolio and downstream certification → JEPA harness.**

The inspected PRs demonstrate parts of this chain, but not a fully authenticated end-to-end execution.

Your first integration task is to map each actual adapter, producer, verifier and consumer to this chain.

For every edge, record:

- Input and output schema.
- Exact source commit and transitive dependencies.
- Content and semantic digest verification.
- Producer/issuer identity and trust boundary.
- Data split and donor identity.
- Measured, structurally unmeasured, rights-withheld and unresolved states.
- What the consumer actually verifies.
- Whether the edge has executed under the required code path.
- What evidence is missing for promotion.

Do not treat a schema match or passing fixture as source authentication.
