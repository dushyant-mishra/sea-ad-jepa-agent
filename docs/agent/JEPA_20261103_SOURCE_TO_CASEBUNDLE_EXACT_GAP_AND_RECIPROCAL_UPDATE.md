## 2. Exact first missing integration edge

**A source/operator/query-bound producer of measured observations + physical/private per-cell library provenance into a source-validated successor of Task5 CaseBundle.** This is a qualification and evidence-binding gap, *not* a lack of public dataset access and not a need for a second synthetic generator or target selector.

The existing Task5 `KNOWN_TRUTH_CASEBUNDLE_V1` is explicitly fixture only. Passing a D1 **student** view to it is wrong: D1 contains only visible-base mapped molecule mass; Task5 V1's `library_size` is a physically measured private-source quantity. **Never fill `library_size` by a D1 sum, fake whole-row count, self-supplied unverified total or source-total-derived student depth.** The lawful physical producer and student redaction remain different rights domains.

Task2 has strong donor-access semantics, not automatic source-feature truth. A new source-bound *version* must retain the existing exact Task2 read/producer receipt, bind a source-native feature→41,238-address identity and per-source/per-operator support, alias rights, q-excluded normalization, actual source/permitted cell roster and donor hierarchy, observed count/physical denominator provenance, QC/source selection class, separately generated student D1 and explicitly concealed query scalar. Ineligible cases must yield `NOT_ESTIMABLE`, not a fabricated observed zero or promoted fixture PASS.

**No schema duplication decision:** use #513's defined eight fields and #379's producer→artifact→executor→verdict authority architecture, not a newly invented issuer/gate family. The required CaseBundle source-binding change must be a separately versioned real-path successor to the fixture-only V1, with a **flat main-based code PR** and exact source/parent-resolving tests once the actionable trusted input object and original source mapping are identified. An in-process hash alone cannot certify that real producer; a hardware signer is optional internal independent-actor hardening, not a data download gate. Do not imply source identity is missing (NPH52 Zenodo 8319719 is known).

### Minimal acceptance/refusal tests for that single future implementation

1. **Reject** V2C/D1 view or a D1-as-physical-library substitute presented as real CaseBundle.
2. **Reject** validly shaped but unresolved manifest/policy/access/issuer digest, forged self-declared rights/status/roster or substituted donor/region/matrix keys.
3. **Reject** when query/right-class mapping or structural measurement is unsupported; NPH52 currently abstains for internal alias/selection qualification, not public access.
4. **Reject** query scalar or its indirect library/normalization/selection descendants on the student side; preserve separate physically private teacher/producer support.
5. **Reject** real and Stage4/training authority from synthetic fixtures and self-declared `PASS` even when tests complete.
6. **Accept only after** the producer is independently source/role bound, Task2 raw-reader-split/crossfit manifest and producer-session receipt resolve, the relevant operator's feature/q support and source-cell permissions are qualified, and existing Task5/6/7/8 consumer obligations are satisfied on the same path. This is a future condition, **not currently accomplished**.
