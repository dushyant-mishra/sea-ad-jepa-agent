The project does not assume that biological/RNA state must compress into one `cell_state` vector. Four representation families remain open and must be compared under the same legality, shortcut and inferential rules.

| Family | Intended scope | Legitimate limitation |
|---|---|---|
| `GLOBAL_CELL_STATE` | Broad shared recoverable RNA structure | May lose genuinely query-local or rare structure |
| `QUERY_LOCAL_STATE` | Address-conditioned/local recoverable RNA structure | Need not represent unrelated global/program information |
| `PROGRAM_STATE` | Program/module/subspace-level recoverable RNA structure | May lose single-address detail or unassigned novelty |
| `STRUCTURED_COMBINED_STATE` | Explicit global + program + local/novelty interface | Complexity is not itself evidence; must beat its component alternatives |

## Neutrality rules

- No family is default or selected.
- The implemented `cell_state` object has no privileged scientific authority.
- Structured-combined is **not** presumed superior merely because it contains more components.
- Network width/dimensionality is not selected here; dimensionality remains evidence-derived.
- A family may legitimately fail to retain information outside the object it is designed to summarize.
- No family is required to recover information that is nonrecoverable from the permitted view.

## Common shortcut firewall

Every family is tested against at least:

- address/gene identity;
- query exchangeability / wrong-query controls;
- capacity-matched global summary;
- source/operator/depth/support structure;
- technical-only structure.

A representation that succeeds through these shortcuts does not qualify merely because its downstream score is high.

## Transport

For every family report separately:

`DONOR_TRANSFER`, `OPERATOR_TRANSFER`, `STUDY_TRANSFER`, `TECHNOLOGY_TRANSFER`.

These are distinct evidence axes, not a single nested ladder.

## Claim limit

Before independent semantic evidence, every family can qualify at most as:

`RNA_REPRESENTATION`
