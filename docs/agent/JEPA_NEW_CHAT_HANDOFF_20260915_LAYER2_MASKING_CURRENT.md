## 14. CorrMask paper and second shortcut class

Paper: `Taking the Easy Way Out: When Single-Cell Foundation Models Learn Shortcuts Instead of Biology`, Machine Learning for Genomics Explorations Workshop at ICLR 2026, OpenReview `KlDSNIvt9A`.

Key mechanism:

Random masking can leave a highly correlated molecular partner visible, letting the model reconstruct a hidden target by local co-expression lookup rather than broader cell-state reasoning.

CorrMask:

- builds a covariance/dependency graph;
- masks correlated partners together;
- uses hybrid structural + random top-up;
- reports hybrid masking outperforming random masking and 100% structural masking;
- reports gains concentrated in underrepresented cell types.

Important paper ablation on 100K Lung:

- Random Macro-F1 ~0.845
- CorrMask-100 ~0.828
- hybrid CorrMask ~0.862

Do not import the paper's λ=0.5 as JEPA authority.

Project synthesis:

1. `CONTEXT_SHORTCUT`: source/operator/donor/cohort context
2. `LOCAL_CORRELATED_GENE_SHORTCUT`: hidden target reconstructed from visible correlated partner

Residual-over-context targets the first. Dependency-aware masking targets the second. They are complementary.
