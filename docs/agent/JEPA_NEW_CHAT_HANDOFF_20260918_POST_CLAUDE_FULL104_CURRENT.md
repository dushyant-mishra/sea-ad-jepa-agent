## Scientific blockers that remain OPEN

These determine whether a FULL104 terminal result is scientifically interpretable.

### H3 — target-panel sizing calibrates planted superiority, not equivalence power — HIGH

`TargetPanelControlVerdictV2.qualified` currently requires an intentionally easy planted shortcut to have a one-sided lower bound > 0 plus replay/coverage/finite checks.

That establishes power for a superiority test on a large/easy effect. The terminal primary question is an **equivalence/null-suppression** question relative to a frozen margin. Those are different power problems.

**Do not run or freeze the target-panel ladder under the current H3 criterion.** First prospectively define a control-only sizing rule that demonstrates enough precision/power to discriminate acceptable residuals inside the margin from unacceptable residuals near/outside the margin. Any change here can change target count and invalidates all downstream authorities that bind it.

### H4 — an all-rung FAIL_CLOSED is not diagnostically identified — HIGH

Before terminal execution, pre-register how to distinguish:
1. targeted masking genuinely does not suppress shortcut structure;
2. the null-equivalence margin is unjustified/too stringent;
3. residual depth/detection-driven predictability is irreducible under the current normalization/threat model;
4. target-panel/uncertainty design lacks equivalence precision.

A multi-hour FULL104 run that only returns `NO_POLICY_QUALIFIED` without discriminating these hypotheses is not an adequate experiment.

### G3 — attacker capacity mismatch — HIGH

Current ridge and nonlinear qualification probes use a 32-feature information set. Production JEPA context is orders richer. A masking PASS therefore supports only:

`SHORTCUT_NOT_DEMONSTRATED_AT_CURRENT_32_FEATURE_ATTACKER_CLASS`

It must not be interpreted as:

`PRODUCTION_JEPA_CANNOT_EXPLOIT_VISIBLE_CONTEXT`

Add a much stronger/capacity-matched, objective-relevant attacker/gate before training, or preserve the limited scope explicitly in every authority.

### G4 — missing biological-signal preservation — HIGH

The current ladder optimizes one side of the tradeoff: defeat shortcut probes with minimal masking. It does not establish that the intended biological/cellular state remains learnable after masking. Retained-address count is not an information-preservation criterion.

Add a prospective signal-preservation/learnability gate using training/control data only.

### G5 — null-equivalence margin lacks a recorded scientific derivation — HIGH

PrecisionAuthorityV4 stores an exact rational, but the builder still accepts numerator/denominator as required CLI arguments. Before terminal authority, record an external scientific rationale or a prospective derivation defining what residual shortcut effect is negligible. Do not choose or retune it after terminal outcomes.

### G2 — targeted-complexity materiality — MEDIUM

Exact lattice arithmetic is mechanically sound, but the current one-total-event equivalence rule remains scientifically under-justified across panel sizes. Resolve prospectively; do not tune from terminal outcomes.
