# Lineage-Composite Production Synthetic Spec — Recursive Self-Audit V1

Date: 2026-10-13  
Audited artifact: `docs/superpowers/specs/2026-10-13-lineage-composite-production-synthetic-design.md`  
Base: PR #328 head `25bbdbe18aa5ed3c8a39a7e4295bc36de1e328ec`  
Verdict: **FAIL_WITH_CORRECTABLE_SCOPE_ERRORS — V1 MUST NOT BE IMPLEMENTED**

## Method

The first production design was challenged against live repository evidence rather than accepted because it was comprehensive. The audit asked:

1. Did the spec promote a historical design or diagnostic into executable scientific authority?
2. Did the spec treat an unfrozen result as frozen?
3. Did it inherit a later lineage wholesale when only a narrow component was qualified?
4. Did it preserve known negative priors and non-authorizing results?
5. Did it state external dependencies that must close before production-scale rehearsal?

## Findings

### A1 — Stage81A3 was described too strongly

**Finding: FAIL.**

The Stage81A3 readout itself records `STAGE81A3 ARCHITECTURE INCOMPLETE`. It is a valuable mechanistic/design ancestor, but the production spec cannot imply that a complete Stage81A3 mechanistic implementation can simply be imported as production biology.

**Repair required:**

- classify Stage81A3 as `MECHANISTIC_DESIGN_ANCESTOR__NOT_DROP_IN_PRODUCTION_AUTHORITY`;
- require exact surviving executable pieces to be located and hash-bound before reuse;
- where no exact implementation survives, reimplement prospectively from the historical design contract and qualify it as new production code rather than claiming byte inheritance.

### A2 — Stage81A3R global-state pilot was treated as stronger authority than it is

**Finding: FAIL.**

The Stage81A3R readout is explicit:

`GLOBAL_STATE_PILOT_INPUT_CONTRACT_LIMITED - NOT FROZEN`

and final status:

`STAGE81A3R_REAL_TRAIN_GLOBAL_STATE_AUDIT_COMPLETE_NOT_FROZEN`.

The global-state basis/dimension pilot cannot become production biological-state authority.

However, the later A3R support/address closure is directly relevant and explicit: exactly three observation states are required — `STRUCTURALLY_UNMEASURED`, `MEASURED_SCALAR`, and `MEASURED_COLLISION_UNRESOLVED` — with collision-unresolved evidence masked from scalar fitting rather than coerced.

**Repair required:**

- separate `A3R_GLOBAL_STATE_PILOT` from `A3R_SUPPORT_ADDRESS_CLOSURE`;
- mark the former non-authority;
- reuse only the latter support/address semantics and exact provenance lessons unless another later authority independently qualifies the global state.

### A3 — Later draft PRs must be inherited component-wise, not by PR status

**Finding: PASS_WITH_REPAIR.**

V72/V75 are open draft PRs, but they contain exact-head tests and narrow qualified mechanics. The production spec must not equate `open draft` with unusable evidence or `green CI` with broad scientific authority.

**Repair required:**

For each inherited component bind:

- exact source head/blob;
- exact qualification artifact/receipt;
- scope of the qualification;
- explicit non-authorities.

Do not inherit a whole PR as one authority object.

### A4 — V75 measurement qualification is narrow

**Finding: PASS_WITH_SCOPE_NARROWING.**

V75 qualifies a 100K measurement architecture, not a biological truth model, not learned representation, and not 500K/full-scale execution.

**Repair required:**

- use V75 for measurement/population mechanics only;
- retain a separate future resource/scale gate before 500K/full-scale realization;
- do not infer biological or representation authority from V75.

### A5 — V78 is correctly negative, but must be machine-prohibited

**Finding: PASS_WITH_HARDENING.**

The design correctly classifies V78 as falsified. A prose statement is insufficient for a production lineage with many historical branches.

**Repair required:**

The implementation must carry a machine-readable negative-prior/supersession registry that rejects accidental imports of prohibited mechanism/config authorities.

### A6 — Query leakage requirements survive audit

**Finding: PASS.**

The design correctly carries the PR #163/#178 result that q can leak indirectly through per-cell normalization/QC descendants even if the visible query token is removed. Query-exchangeability and capacity-matched controls remain required.

No repair.

### A7 — Regulatory V53-V58 should remain hostile-test ancestry only

**Finding: PASS.**

The design does not promote their numerical margins or synthetic cis structures to human biology. Their matched-nuisance, mixed-sign, underpower and semantic-twin lessons are legitimate hostile-test requirements.

No repair.

### A8 — PR #328 is still only the implementation base

**Finding: PASS.**

The design correctly preserves PR #328 as software/mechanics/interface qualification and does not relabel it as complete production substrate.

### A9 — Final physical blinding is not yet implemented

**Finding: PASS_WITH_EXPLICIT_DEPENDENCY.**

PR #328 controller separation is logical/artifact-level. The final sealed production qualification requires separate producer/fit/controller execution domains following the stronger PR #318-#321 packaging pattern.

This is a required future implementation unit, not an already-closed property.

### A10 — Downstream target-portfolio abstraction is an external blocker

**Finding: MISSING_DEPENDENCY IN V1.**

The downstream harness historically represented one `selected_candidate` and cannot faithfully encode a general independent multi-block portfolio. The production synthetic same-pipeline rehearsal must not declare full downstream qualification until that separate downstream repair is present and hash-bound.

**Repair required:**

Add explicit dependency gate:

`BLOCKED_DOWNSTREAM_TARGET_PORTFOLIO_MULTI_BLOCK_REPAIR_REQUIRED`

for any rehearsal that claims final portfolio semantics.

### A11 — Realization scale and canonical address width must remain separate

**Finding: PASS_WITH_CLARIFICATION.**

Canonical 41,238-address width is required for production reader compatibility. Full 4.55M-cell scale is not automatically required. Cell-count scale must be separately resource-qualified.

**Repair required:**

Make this separation explicit in v2.

## Corrective action

V1 is preserved unchanged as audit evidence and classified:

`SUPERSEDED_BY_RECURSIVE_SELF_AUDIT_V2__DO_NOT_IMPLEMENT`

A corrected v2 must:

1. classify Stage81A3 as design/mechanics ancestry only;
2. split A3R global-state non-authority from A3R support/address authority;
3. require component-level exact-head/blob/receipt bindings for every inherited lineage;
4. add the downstream multi-block portfolio dependency;
5. explicitly separate address width from cell-count scale;
6. retain all prior negative-prior, blinding, query-leakage, multimodal, regulatory, support and authority boundaries.

No code, generator realization, fit, score or training is authorized by this audit.
