# External review method

1. Re-fetch live source heads before importing or judging code.
2. Inspect authority/governance first, then executable paths and tests.
3. Reproduce defects with minimal adversarial tests before fixing.
4. Preserve V20 immutability and protected data seals.
5. Keep reviewer-run evidence separate from producer-reported evidence.
6. Implement only on the isolated repair branch and re-review each change.
