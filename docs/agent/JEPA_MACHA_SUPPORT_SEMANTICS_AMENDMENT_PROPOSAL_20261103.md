## 2. The amendment: five rules, as a new versioned observation process
1. **Address binding.** Before generation, each synthetic gene *j* is bound to a real molecular address *a_j* by a committed, outcome-blind rule: V3.1.1 seed commit-and-reveal over the address registry. The binding is recorded in the new world receipt.
2. **Operator binding.** Each synthetic operator inherits exactly one real matrix of its source stratum (HVS from 24, SEA-AD from 11, NPH52 from 7). NPH52-like operators therefore differ by cell type, as in the real data.
3. **Structural state.** For each (operator, *j*), the state is E1[matrix, *a_j*], cross-checked against E2, failing closed on disagreement.
   - `MEASURED_SCALAR` entries may carry **zero** counts, and a zero there remains measured.
   - `STRUCTURALLY_UNMEASURED` entries carry no value: a mask, never 0.
   - `MEASURED_COLLISION_UNRESOLVED` entries are never coerced to measured or to zero, and never enter D1.
4. **Detection.** Counts are drawn only on `MEASURED_SCALAR` entries, using E4 as the detection probability, plus any program-induced positives. Changing the detection parameters must change **no** state bit.
5. **Rights.** `WITHHELD_BY_EVIDENCE_RIGHTS` applies only in the student view (E5 and E7), with the E6 alias rules. Hidden totals are never visible to the student.

These five rules separate the five quantities: structural assay absence (rule 3), measured zero (rule 3), detection probability (rule 4), collision-unresolved features (rule 3), and evidence-rights withholding (rule 5).

## 3. Consequences that can be tested in advance (hostile tests before any exposure)
P1, P3 and P4 are computable from metadata alone, before any count exists, which is what makes them falsifiable.

| ID | Prediction | Failure means |
|---|---|---|
| P1 | States are bit-identical when detection parameters change. | Detection leaks into support (the PR #328 defect). |
| P2 | Measured-zero entries exist wherever detection probability is low on `MEASURED_SCALAR` entries, and are reported as measured. | Zero coerced to absence. |
| P3 | Per-stratum measured fractions over the bound addresses equal E1/E2 exactly: constant across matrices within HVS and within SEA-AD, varying across NPH52 matrices. | Support no longer follows the real tables. |
| P4 | Estimability of a #526-style fixed panel is **predicted from states alone before generation**, and the generated diagnostic must equal that prediction (plus positive-denominator NOT_ESTIMABLE). | Support and estimation are inconsistent. |
| P5 | No collision-unresolved entry is coerced, and collision mass is absent from D1. | Collision leak. |
| P6 | Each C3 query address has a **predeclared wrong-query address** with the same state pattern and similar detection probability. | No wrong-query control: none exists in any current asset. |
