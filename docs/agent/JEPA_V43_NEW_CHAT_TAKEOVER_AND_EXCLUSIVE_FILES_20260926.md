## Scientific objective — this is what matters

The **teacher's task is constructing a biologically faithful query-address-conditioned, non-scalar, same-cell molecular state**. It may need the queried measured value to do so; that is NOT automatically a violation. The student uses lawful incomplete remaining RNA and canonical q to predict the estimable part of this meaningful state and must not receive direct or derived hidden q information through normalization, pooled features, QC or metadata. No teacher state is declared biologically faithful merely because it is high-dimensional or because students fit it. Observational cross-gene associations are NOT causal perturbation predictions.

The USER suggested complementary teachers plus specialist students to preserve rare biology in a 4.55M-cell / 104-donor / 42-operator highly heterogeneous dataset. V43 compares *three* research arms: (A) one native-rich EMA teacher/single student; (B) shared EMA backbone with distinct common/fine/conditional rare heads and shared student; (C) independently specialized common/fine/rare teacher team plus core and fine/rare students. A/B/C are **NOT ranked or selected**. Each teacher's information, q policy, biological falsifier and source/EMA lineage must be prospectively specified. Train/dev populations and all numeric hyperparameters/thresholds remain `UNSET_REQUIRES_APPROVAL`, not inherited from historical mechanics runs.

Historical support: main's Sept8 V5 design established 17,186 measured-address common core and native-support views; the older Stage69 auxiliary rare result was not a lock, Stage70 rare vs Stage27C repeated-bootstrap CI crossed zero; Stage71 real graph underperformed randomized graph on its test and rare representation/prediction locks failed. V43 starts by defining biological falsifiers and testing under capacity-matched control rather than training more expert heads prematurely.
