The current authority index preserves the general successor lesson from T0 Step 4:

- 1:1 QC matching removed Q_DEPTH/Q_DETECT imbalance but also destroyed held-out-statistic detectability;

## 4. T0-derived design principles that should feed Target Discovery

The following are transferable design rules, not T0 target authority:

### 4.1 Precommit before outcome access

Method, estimator family, thresholds, ranking/tie-breaks, nuisance design, power rule, and STOP conditions should be frozen before opening confirmation outcomes.

For Target Discovery this means no post-hoc choice of molecular view, locality, neighborhood, embedding dimension, null definition, or acceptance threshold after observing the candidate result.

### 4.2 Discovery and confirmation must be causally separated

A donor/outcome used to choose the method cannot later be called fresh confirmation.

The Target Discovery analogue is that a panel/view/null/locality used to choose the relational object cannot then serve as independent evidence for that same choice without an explicit prospective replication layer.

### 4.3 Cross-fitting is not automatically a lower bound

T0 V21 explicitly corrected the claim that cross-fitting creates a lower bound. It removes in-sample optimism but does not by itself produce conservative transport authority.

For Target Discovery/V5, held-out embeddings or donor-held-out predictions should not be relabelled conservative merely because they are cross-fitted; acceptance needs an explicitly defined uncertainty/influence/worst-case rule.

### 4.4 Gate power/discrimination must be demonstrated at exact geometry

A rejection gate can invalidate good biology if its matching or intervention geometry destroys signal. Therefore every rejection-capable anti-cheat gate needs both:

- invalid controls it must reject; and
- valid biological controls it must retain,

at the exact sample/mask/matching geometry used in production qualification.

### 4.5 Association is not intervention

Cross-cell correlation of a target/latent with depth, detection, source, operator, or QC is warning evidence. Strong rejection authority should come from same-cell or otherwise causally interpretable interventions where possible.

This directly motivates evidence-thinning, depth-thinning, support counterfactuals, mask-only attacks, and same-cell measurement perturbations in V5.

### 4.6 `NOT_MEASURABLE` is not PASS

T0 repeatedly enforced the distinction among PASS, FAIL, NOT_MEASURABLE, and authority STOP. The same discipline should apply to Target Discovery: insufficient support, unresolved triplets, non-derangeable strata, or missing measurement authority cannot silently become success.

### 4.7 Provenance closure is part of scientific validity

T0 B1/B2 review showed that logical identity, physical bytes, source rows, row-address semantics, manifests, and parent roots can create silent false confidence if not bound end-to-end.

Target Discovery/V5 should inherit the same principle: an apparently valid biological relation is not qualified if the molecular rows, support masks, source identities, target triplets, or checkpoint bytes are not exactly bound to the claimed authority.

### 4.8 Donor is the primary generalization unit

T0's donor-disjoint development/confirmation discipline reinforces the Target Discovery donor-primary recurrence rule. Large cell counts must not substitute for donor-level independence.

### 4.9 Power and estimability precede irreversible opening

Before spending a protected partition or declaring a definitive test, establish that the proposed test can answer the question at the available donor count and nuisance burden.

In the broader JEPA pipeline this generalizes to: do not open reader_validation/oracle or consume scarce holdout biology for a gate whose power or estimability has not been demonstrated prospectively.

## 5. T0 lessons already visible in V5 anti-cheat design

The Sep-9 `TEACHER_STUDENT_V5_ANTI_CHEAT_AND_T1_MECHANICS_FINDINGS_20260909.md` shows the broader pipeline already absorbed these ideas.

It requires or motivates:

- support-only source attack;
- depth/QC-only attack;
- mask-only attack;
- support counterfactual;
- operator/source conditional probe;
- donor memorization probe;
- held-out donor transfer;
- held-out operator/matrix transfer;

- evidence-response curve;
- depth-response curve;
- proposal-weighting p/q audit;
- collapse / constant-vector / low-rank controls;

- checkpoint telemetry that can STOP low-loss but biology-destructive training.

The same file also formalizes the observation-channel vs biology-channel split: measurement/support/depth/technology facts may be used to interpret evidence but must not be allowed to masquerade as `z_bio`.

This is exactly the kind of cross-lane anti-cheat architecture T0 lessons were meant to inform.

## 6. What T0 should NOT contribute

Methodological influence must not become biological leakage.

T0 must not supply to Foundation Target Discovery/V5:

- AT8/pathology values as target-selection inputs;
- the T0 broad-IMMUNE score as an automatic JEPA teacher target;
- T0-specific operator-31 population as the V5 production population;
- V20/V21 numerical thresholds as production Target Discovery thresholds by inheritance;
- confirmation outcomes for tuning masks, relational geometry, latent dimension, locality, or anti-cheat thresholds.

The information flow is **methodological**, not outcome/target leakage.
