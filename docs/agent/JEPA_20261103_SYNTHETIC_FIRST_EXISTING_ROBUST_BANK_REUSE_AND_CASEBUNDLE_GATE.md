### Why this is more than another software-green test

The criterion is not simply that existing code runs. It is that the test shows the **same real scientific trust obligations** survive under multiple original frozen donor/source/measurement perturbations:
- Base q count can be withheld without arithmetic leakage if all source-hidden molecules are accounted for.
- **Off-ledger withheld mass still changes D1**; an upstream physical source/alias closure is missing.
- The source-id is a self-declared string; an attacker can forge source labeling within a fixture and still get an unauthenticated, nonpromoting output.
- If query is classified BASE, PR474 has no external q issuer identity with which to refuse the exposure.
- Private full physical source mass **is not** student projected normalization depth; richer observations can exceed that depth, so current Task5 library semantics cannot represent both correctly.
- Zero detection with measured support (especially V80 SP05) is **not** structural unmeasurement; nonestimability must be explicit.

Each recorded weakness becomes an **explicit falsification test for the *next* proposed real source/path adapter**. The current synthetic result is **not** sufficient for source authentication, q-dependent selection independence, a new rich teacher, or Stage4 training.
