# Historical water-fill clarification

The 2026-08-24 calibration bundle contains `sampler/t1_historical_waterfill_donor_quotas.csv`.

That artifact is a donor/presentation quota allocation scheme. It is not evidence of a frozen waterfall of biological targets.

Keep these four concepts separate:
1. donor water-fill sampling;
2. rejected tier-hiding/cascade target attempts;
3. evidence-response waterfall (20→40→60→80→100);
4. any new coarse→fine biological target hierarchy proposed by Target Discovery V1.

They may not be used interchangeably in future history summaries.
