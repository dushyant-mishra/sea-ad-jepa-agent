# Target-discovery convergence V1

Status: prospective metadata-only decision law. No biological execution, target selection, representation selection, TD60, Stage 4, or training authority.

## Purpose

This is the final no-authority convergence adapter for foundation target discovery after corrected replay and candidate qualification. It consumes already-adjudicated candidate statuses from routing V4 and, only when needed, protected head-to-head V2 metadata. It does not open biological values or compute candidate gates.

Foundation candidates are exactly:
`C1_SHARED_EMERGENT`, `C2_RELATIONAL_SHARED`, `C3_QUERY_MEASURED`, `C6_SHARED_QUERY_COMPOSITE`, `C4_STRUCTURED_COMPOSITE`.
C5 remains an optional specialist and can never rescue the absence of a foundation target.

## Survivor law

Input candidate statuses use routing V4 semantics. Composite dependency resolution must be applied before convergence.

- any unresolved foundation candidate -> `FOUNDATION_CANDIDATE_UNRESOLVED__CONTINUE_TESTABLE_ROUTES__NO_TARGET_AUTHORITY`;
- zero eligible -> `NO_TARGET_WINNER__REDESIGN_BEFORE_PROTECTED_CONFIRMATION`;
- exactly one eligible -> that candidate becomes the protected-confirmation finalist;
- two or more eligible -> complete protected head-to-head V2 evidence is mandatory.

## Multiple-survivor law

For multiple eligible candidates, convergence delegates to protected head-to-head V2 without changing its seven dimensions or dominance law.

- unique head-to-head leader -> protected-confirmation finalist;
- incomparable complete evidence -> `MULTIPLE_QUALIFIED_TARGETS__INCOMPARABLE__NO_TARGET_AUTHORITY`;
- missing/NOT_ESTIMABLE pairwise evidence -> `HEAD_TO_HEAD_UNRESOLVED__NO_TARGET_AUTHORITY`.

No aggregate score, rank sum, post-hoc weight or best-looking loser is permitted.

## Protected confirmation law

Protected confirmation is represented only by prospectively thresholded status `PASS`, `FAIL`, or `NOT_ESTIMABLE` for the frozen finalist.

- before confirmation -> `PROTECTED_CONFIRMATION_REQUIRED__NO_TARGET_AUTHORITY`;
- PASS -> `TARGET_CANDIDATE_CONFIRMED__OWNER_SELECTION_DECISION_REQUIRED__NO_TARGET_AUTHORITY`;
- FAIL -> `PROTECTED_CONFIRMATION_FAILED__NO_TARGET_WINNER__REDESIGN`;
- NOT_ESTIMABLE -> `PROTECTED_CONFIRMATION_NOT_ESTIMABLE__NO_TARGET_AUTHORITY`.

Even confirmation PASS does not set `target_selected=true`; an explicit owner selection decision remains separate.

## Authority boundary

Every output keeps biological value read, corrected replay, target selection, representation selection, TD60, Stage 4 and training authority false.
