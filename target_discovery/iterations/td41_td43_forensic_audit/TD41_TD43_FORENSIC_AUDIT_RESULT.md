The apparent arithmetic contradiction came from treating the two half libraries as independent thinnings. They are complementary binomial partitions. For a full-depth unequal pair, both halves cannot simultaneously tie, because equal counts in both halves would imply equal full counts.

The wrong-cell 0.484 value is therefore not a swapped same-cell arm. It includes tie–tie matches that are mathematically impossible for the same cell under complementary splitting.

Conceptual correction:
TD41 should be described as a **within-cell pairwise concordance/order geometry**. The 4,096-pair representation is a Monte Carlo approximation to the complete pair-sign embedding. Because the downstream statistic donor-averages pair signs, standardizes each pair across states, and then computes Euclidean state geometry, it is not literally a simple cell-to-cell Kendall tau coefficient.
